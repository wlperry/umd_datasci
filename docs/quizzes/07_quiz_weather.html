Data: dlh_temp_df has one row per day for Duluth (UPPERCASE columns: TEMP, YEAR, MONTH, DAY, YEARMODA). dlh_year_df is one row per year. The trend model is lm(TEMP ~ YEAR, data = dlh_year_df).

Downloading the data

1. (MC) Which function and package downloaded the Duluth record into R?

a. read_csv() from readr
b. get_GSOD() from GSODR
c. download.file() from base R
d. import() from rio

2. (MC) Why do we run select() right after downloading the raw weather data?

a. select() is required before ggplot() will run
b. get_GSOD() returns 40+ columns and we only need a handful
c. select() converts daily data to yearly
d. R will not store the object otherwise

3. (MC) dlh_temp_df %>% select(temp) errors even though a temperature column exists. Why?

a. select() cannot take one column
b. The column is named TEMP (uppercase) — R is case-sensitive
c. You need library(GSODR)
d. temp is a reserved word

4. (Fix) dlh_temp_df %>% select(temp, YEAR, MONTH) errors with Column 'temp' doesn't exist. How do you find the right name?

a. Run names(dlh_temp_df) and use the exact (uppercase) name: select(TEMP, YEAR, MONTH)
b. Reinstall GSODR
c. Use filter() instead of select()
d. Add quotes: select("temp")

5. (MC) The difference between YEARMODA and the separate YEAR, MONTH, DAY columns is:

a. YEARMODA is one combined date value (good for a time axis); YEAR/MONTH/DAY are the same date split into three numbers (good for group_by())
b. They hold completely different dates
c. YEARMODA is text and the others are dates
d. There is no difference

Summarizing over time

6. (T/F) Summarizing daily data to yearly means “loses information” in a bad way and makes the analysis weaker.

True / False

7. (Predict) dlh_temp_df has ~28,000 daily rows (1948–2025). After group_by(YEAR) %>% summarize(TEMP = mean(TEMP, na.rm = TRUE)), the result has about:

a. 28,000 rows b. 78 rows (one per year) c. 12 rows d. 1 row

8. (T/F) mean(TEMP) returns NA for a year if any single day that year is missing; mean(TEMP, na.rm = TRUE) fixes it.

True / False

9. (Fix) This returns NA for every year. What is missing?

dlh_temp_df %>%
  group_by(YEAR) %>%
  summarize(TEMP = mean(TEMP))

a. na.rm = TRUE inside mean()
b. arrange(YEAR) before summarize()
c. A library() call
d. Nothing — this is correct

Modeling the trend with lm()

12. (MC) In lm(TEMP ~ YEAR, data = dlh_year_df), which is the response and which is the predictor?

a. YEAR is the response, TEMP is the predictor
b. TEMP is the response, YEAR is the predictor
c. Both are predictors
d. Both are responses

13. (MC) To get the rate of warming per year from yearly_temp_model, you extract:

a. coef(yearly_temp_model)[1] — the intercept
b. coef(yearly_temp_model)[2] — the slope
c. summary(yearly_temp_model)$r.squared
d. residuals(yearly_temp_model)

14. (Fix) A student wants the warming rate but writes this. What did they extract?

yearly_temp_model <- lm(TEMP ~ YEAR, data = dlh_year_df)
warming_rate <- coef(yearly_temp_model)[1]

a. They grabbed the intercept; use coef(yearly_temp_model)[2] for the slope
b. They grabbed the slope; that is correct
c. coef() should be resid()
d. [1] should be ["YEAR"] — same thing, no bug

15. (Predict) lm(TEMP ~ YEAR, data = dlh_year_df) gives a slope of 0.025 with p < 0.001. The one-sentence conclusion is:

a. There is no evidence of a trend
b. Duluth’s annual mean temperature is rising at a statistically significant rate (~0.25 °C/decade)
c. Every year is exactly 0.025 °C warmer with no uncertainty
d. The model failed to converge

16. (T/F) A yearly slope of 0.02 °C/year is trivial and cannot represent a meaningful long-term change.

True / False

17. (T/F) Multiplying a yearly warming slope by 10 converts it to °C per decade.

True / False

18. (T/F) ★ A yearly temperature time series can violate the independence assumption of lm() because a warm year tends to be followed by another warm year (autocorrelation).

True / False

19. (MC) ★ A student fits the trend model directly on the ~28,000 daily rows. It runs without error. What is the problem?

daily_trend_model <- lm(TEMP ~ YEARMODA, data = dlh_temp_df)

a. There is no problem — more rows is always better
b. Each row is still one day, so the residuals still carry the huge seasonal swing (~30 °C) that is not the signal of interest; the yearly summary removes that noise first
c. lm() cannot handle a date column
d. YEARMODA must be YEAR

case_when() and seasons

20. (MC) case_when() comes from which package (part of the tidyverse)?

a. GSODR b. dplyr c. ggplot2 d. lubridate

21. (Fix) Every row comes back NA for season. What is wrong?

dlh_temp_df %>%
  mutate(season = case_when(
    MONTH == c(6, 7, 8) ~ "summer",
    TRUE ~ "other"
  ))

a. case_when() cannot make text
b. MONTH == c(6, 7, 8) compares element-by-element; use MONTH %in% c(6, 7, 8)
c. TRUE ~ "other" must come first
d. mutate() should be summarize()

22. (Fix) This is meant to keep only summer and winter rows but silently keeps every row. What is wrong?

season_year_df <- dlh_season_df %>%
  filter(season == c("summer", "winter"))

a. filter() needs group_by() first
b. season == c("summer", "winter") compares element-wise; use season %in% c("summer", "winter")
c. The strings need to be capitalized
d. filter() should be select()

23. (Predict) Seasons are defined as summer = 3 months, winter = 3 months, shoulder = the other 6. In count(season), which category has the most rows?

a. summer b. winter c. shoulder (about twice either single season) d. they are all equal

Comparing seasons in a plot

24. (T/F) To split points by season in a ggplot, you need color = season inside aes().

True / False

25. (Fix) In season_temp_plot, every point is the same default color instead of split by season. What line is wrong or missing?

season_year_df %>%
  ggplot(aes(x = YEAR, y = TEMP)) +
  geom_point() +
  geom_smooth(method = "lm")

a. color = season is missing from aes()
b. geom_point() should be geom_line()
c. method = "lm" should be method = "loess"
d. You need facet_wrap(~season)

26. (MC) In a plot with a separate geom_smooth(method = "lm") line per season, how do you tell which season is warming faster?

a. Whichever line starts higher on the y-axis
b. Whichever line is steeper (bigger slope)
c. Whichever line is a different color
d. Whichever season has more points
