Answer key (instructor copy — remove before distributing)

Q Type Answer
1 T/F FALSE — raw daily data hides the trend in seasonal noise; yearly summaries reveal it
2 MC B
3 Code See below
4 Predict 0.02 × 10 = 0.2 °C per decade
5 Match 1–B, 2–D, 3–A, 4–C
6 Code See below
7 Error Use %in%, not ==, for multiple values: MONTH %in% c(6, 7, 8)
8 MC B — degrees per year (X is YEAR)
9 Code yearly_temp_model <- lm(TEMP ~ YEAR, data = dlh_year_df)
10 T/F TRUE — a sampling-bias caveat

Q3 model answer

dlh_temp_df %>%
  group_by(YEAR) %>%
  summarize(mean_temp = mean(TEMP, na.rm = TRUE))

Q6 model answer

dlh_temp_df %>%
  mutate(season = case_when(
    MONTH %in% c(6, 7, 8)  ~ "summer",
    MONTH %in% c(12, 1, 2) ~ "winter",
    TRUE                   ~ "shoulder"
  ))
