Quiz 03: Wrangling and Summary Statistics

Instructions

This quiz has four parts: general knowledge, predicting code output, troubleshooting broken code, and open-ended concept questions. It covers the tidyverse verbs (filter, select, mutate, arrange, summarize), the pipe, and descriptive statistics (mean, median, SD, SE, and counting n correctly) on our leaf data (tree_df: side, weight_g, width_cm, height_cm).

Grading: 28 questions × 1 point = 28 points total. Partial credit is available on code and troubleshooting questions.

Answer key (instructor copy — remove before distributing)

Q Type Answer
1 MC B
2 Match 1–B, 2–D, 3–E, 4–A, 5–C
3 Concept = assigns; == tests equality. filter(side = "sunny") errors: “We detected a named input… you’ve used = instead of ==”
4 T/F TRUE
5 MC B
6 Concept length() counts every position including NAs; use sum(!is.na(x)) to count only real values
7 MC C
8 Predict Rows where side is “sunny” and weight_g > 5; some subset of the 10 sunny rows (fewer than 10)
9 Predict 3 columns: side, weight_g, weight_mg — select() first drops to 2, mutate() adds one back
10 Predict 3 — three non-NA values in x
11 Predict 2 rows — one per level of side (sunny, shady)
12 Predict Mean = 15.2, median = 7; median is fairer — the outlier (50) pulls the mean up but doesn’t affect the median
13 Predict (1) keep rows with weight_g > 0; (2) keep only side, weight_g, height_cm columns; (3) sort by side, then by weight_g descending within side
14 Predict .x stands in for whichever column across() is currently processing; result has 3 mean columns (one per listed column), per group
15 Error Single = instead of ==; fix: filter(side == "sunny")
16 Error weight_g contains NA, and no na.rm = TRUE was supplied, so the result silently becomes NA; fix: mean(tree_df$weight_g, na.rm = TRUE)
17 Error Trick — this is actually correct: select(-weight_g, -height_cm) drops those two columns and keeps everything else, which is the opposite of what the student wanted. Fix: select(weight_g, height_cm) (no minus signs)
18 Error length(sunny_wt) counts NAs too; should be sum(!is.na(sunny_wt))
19 Error The result of mutate() was never assigned back to tree_df (or a new object) — mutate() doesn’t modify in place; fix: tree_df <- tree_df %>% mutate(...)
20 Error se_wt references sd_wt and n before they are created — lines inside summarize() run top to bottom, so n and sd_wt must be defined first
21 Error R is case-sensitive; the data stores "sunny" (lowercase), not "Sunny"
22 Concept H₀: no difference in leaf weight between sides; Hₐ: leaf weight differs between sides. A prediction (“shady leaves will be heavier”) is a specific, directional expectation; H₀/Hₐ are the formal statistical statements a test evaluates, and Hₐ here is non-directional unless stated otherwise
23 Concept SD describes spread of individual data points; SE describes precision/uncertainty of the sample mean. We report SE for group-mean comparisons because that’s the quantity whose uncertainty matters for the comparison
24 Concept Close mean/median → roughly symmetric distribution; mean ≫ median → right-skewed (a few large values pulling the mean up)
25 Concept Loading libraries up front makes every dependency visible at a glance, avoids “could not find function” errors mid-script, and means the whole script’s requirements are documented in one place
26 Concept Smaller — SE = SD/√n, so a larger n increases the denominator, shrinking SE (more data → more precise estimate of the mean)
27 Concept The pipe reads top-to-bottom in execution order; nested calls bury the first-executed step in the middle, making the sequence of operations hard to trace
28 Concept E.g. group_by(side, size_class); rows = number of unique side × size_class combinations present in the data (up to 2 × number of size classes)
