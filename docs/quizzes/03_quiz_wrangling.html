Q Type Answer
1 T/F FALSE — filter() picks rows, select() picks columns
2 MC B — == tests equality; = assigns and errors here
3 Match 1–C, 2–E, 3–B, 4–A, 5–D
4 Predict length(x) → 5; sum(!is.na(x)) → 3
5 Code See below
6 Error length() counts the NA; use n <- sum(!is.na(weights)) → n = 3
7 Code See below
8 MC B — the outlier inflates the mean; median is robust
9 Code See below
10 Concept SD = spread of individual values; SE = precision of the mean; SE shrinks as n grows

Q5 model answer

tree_df %>%
  filter(weight_g > 0) %>%
  select(side, weight_g) %>%
  arrange(desc(weight_g))

Q7 model answer

tree_df %>%
  group_by(side) %>%
  summarize(
    n       = sum(!is.na(weight_g)),
    mean_wt = mean(weight_g, na.rm = TRUE)
  )

Q9 model answer

tree_df %>%
  mutate(
    weight_mg  = weight_g * 1000,
    size_class = if_else(weight_g > 5, "large", "small")
  )
