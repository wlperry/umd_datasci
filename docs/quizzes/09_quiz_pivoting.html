Wide vs. long (tidy) data

1. (T/F) ggplot() and group_by() generally need data in long (tidy) format, not wide.

True / False

2. (MC) A file has one row per day and one column per year (53 year-columns). To plot ice cover over time you first:

a. pivot_wider() the years into more columns
b. pivot_longer() the year-columns into a single year column
c. filter() out the years
d. arrange() by year

3. (T/F) You cannot group_by(year) on wide data with one column per year, because there is no year column to group by yet.

True / False

4. (T/F) “Tidy” data means every variable is its own column and every observation is its own row.

True / False

pivot_longer() and pivot_wider()

5. (MC) pivot_longer() is used to:

a. Turn many columns into two key–value columns (tidy it)
b. Make a human-readable summary table
c. Keep the highest-value row per group
d. Split the data into groups

6. (MC) pivot_wider() is used to:

a. Turn many columns into key–value pairs
b. Spread tidy data back out into a wide, human-readable table
c. Drop missing values
d. Sort rows high to low

7. (Predict) ice_raw has 190 rows and 53 year-columns plus a date column. After pivot_longer(cols = -date), the result is about:

a. 3 columns, ~10,000 rows
b. 53 columns, 190 rows
c. 2 columns, 243 rows
d. Unchanged

8. (Predict) pivot_wider(id_cols = year, names_from = month, values_from = ice_cover) produces:

a. One row per month, one column per year
b. One row per year, one column per month
c. A single column
d. The same shape as the input

9. (Fix) ice_raw %>% pivot_longer(cols = -date, names_to = "year") errors with Column 'date' doesn't exist. The day labels are still row names. What is missing?

a. rownames_to_column(var = "date") before the pivot
b. library(tidyr)
c. A values_to argument
d. arrange(date)

10. (Fix) ★ After pivot_longer() the new year column holds values like "X1998" instead of 1998. Which argument strips the leading "X"?

a. names_prefix = "X"
b. values_drop_na = TRUE
c. names_sep = "X"
d. cols = -X

slice_max() and reading messy files

11. (MC) To keep, for each year, the single row with the highest ice_cover, you use:

a. group_by(year) %>% slice_max(order_by = ice_cover, n = 1)
b. filter(ice_cover == max)
c. arrange(ice_cover) %>% head(1)
d. pivot_wider(ice_cover)

12. (T/F) slice_max(n = 1) without group_by() first returns the single highest row in the whole data set, not one per group.

True / False

13. (MC) ★ A NOAA text file is space-separated, not comma-separated. Which is true?

a. read_csv() is fine — it auto-detects any separator
b. Use read_table() / read_delim(); read_csv() expects commas and would misparse it
c. You must open it in Excel first
d. Space-separated files cannot be read into R

14. (Fix) read_csv("data/noaa_ice.txt") reads the whole file into a single column. Why?

a. The file is space/tab-separated, not comma-separated; use a reader that matches the delimiter
b. .txt files cannot be read
c. You need library(readr)
d. The file is empty
