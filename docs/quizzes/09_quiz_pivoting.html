Answer key (instructor copy — remove before distributing)

Q Type Answer
1 T/F TRUE
2 MC B — pivot_longer() the year-columns
3 Predict 3 columns; ~190 × 53 ≈ 10,000 rows
4 Match 1–C, 2–B, 3–D, 4–A
5 Code See below
6 Error Add rownames_to_column(var = "date") first — the day labels were row names, not a column
7 Code See below
8 MC B
9 T/F TRUE
10 Concept Use read.table() (or read_delim) for space-separated data; read_csv() expects commas and would misparse it

Q5 model answer

ice_raw %>%
  pivot_longer(
    cols = -date,
    names_to = "year",
    names_prefix = "X",
    values_to = "ice_cover"
  )

Q7 model answer

ice_clean %>%
  group_by(year) %>%
  slice_max(order_by = ice_cover, n = 1, with_ties = FALSE)
