Question 10 · Short answer — the guiding question

In one sentence, what single question should you ask to decide which join to use?

Answer key (instructor copy — remove before distributing)

Q Type Answer
1 T/F TRUE
2 MC B — ~4,000 (only matches)
3 Match 1–B, 2–A, 3–D, 4–C, 5–E
4 Predict Joins on index (the shared column) — matches by row number, gluing data to the wrong rows; always name the real key
5 Code left_join(reports, locations, by = c("REPORT_NUMBER" = "number"))
6 Code mutate(REPORT_NUMBER = as.integer(REPORT_NUMBER))
7 Code anti_join(reports, locations, by = c("REPORT_NUMBER" = "number"))
8 MC B — left_join keeps every report
9 T/F FALSE — filtering joins keep rows only, no new columns
10 Concept “Which rows do I refuse to lose?” — that answer picks the join
