Quiz 06 — Regression

lm(), slope and intercept, R-squared, residuals, and prediction

Instructor note — this is a question bank, not the handout. Pick ~10 questions (spread across topics and types), delete the rest, this note, and the answer key. Tags: (MC) · (T/F) · (Predict) predict the output · (Fix) spot the mistake. ★ marks a harder question.

Data: paper_df has mass_g and area_cm2 for paper squares of known area. The class model is paper_lm_model <- lm(area_cm2 ~ mass_g, data = paper_df).

The lm() formula

1. (MC) In lm(area_cm2 ~ mass_g, data = paper_df), the ~ means:

a. “is approximately equal to”
b. “is modeled as a function of” — area (left) is the response, mass (right) is the explanatory variable
c. “divided by”
d. “not equal to”

2. (MC) Which variable is the response and which is the explanatory variable here?

a. area_cm2 is the response, mass_g is explanatory
b. mass_g is the response, area_cm2 is explanatory
c. Both are responses
d. Both are explanatory

3. (Fix) A student wants to predict area from mass but writes this. What is the fix?

paper_lm_model <- lm(mass_g ~ area_cm2, data = paper_df)

a. lm(area_cm2 ~ mass_g, data = paper_df) — the response goes on the left of ~
b. lm(area_cm2 == mass_g, data = paper_df)
c. lm(paper_df, area_cm2, mass_g)
d. Nothing is wrong

4. (MC) H₀ and Hₐ for the slope β in a simple linear regression are:

a. H₀: b = 1 ; Hₐ: b > 1
b. H₀: b = 0 (X does not predict Y) ; Hₐ: b ≠ 0 (X does predict Y)
c. H₀: R² = 0 ; Hₐ: R² = 1
d. H₀: the data are normal ; Hₐ: the data are not normal

Slope, intercept, and R²

5. (MC) In \(\hat{Y} = a + bX\), what is b?

a. The predicted value of Y when X = 0
b. The change in Y for every 1-unit increase in X (the slope)
c. The correlation between X and Y
d. The total variation explained

6. (MC) R² measures:

a. The probability the null hypothesis is true
b. The slope of the line
c. The proportion of variation in Y explained by X
d. The number of residuals above zero

7. (Predict) coef(paper_lm_model) prints two numbers. Which is which?

a. The first is (Intercept) = a ; the second is mass_g = b (the slope)
b. The first is the slope ; the second is the intercept
c. Both are R² values
d. Both are p-values

8. (Predict) Given b_slope <- 130.5 and a_intercept <- 0.28, what prints?

mass_sunny <- 0.092
area_sunny <- b_slope * mass_sunny + a_intercept
cat("Predicted area:", round(area_sunny, 2), "cm2\n")

a. Predicted area: 12.29 cm2
b. Predicted area: 130.5 cm2
c. Predicted area: 0.28 cm2
d. An error

9. (T/F) For paper of uniform stock, mass and area are nearly perfectly linearly related, so R² should be close to 1.

True / False

10. (T/F) An R² of 0.45 in an ecological dataset is worthless and should not be reported.

True / False

11. (Predict) summary(paper_lm_model) shows Pr(>|t|) for the mass_g row as < 2e-16. What does that tell you?

a. The intercept is zero
b. Reject H₀: mass is a statistically significant predictor of area
c. R² is exactly 1
d. The residuals are not normal

Residuals and least squares

12. (MC) A “residual” is:

a. The predicted value of Y
b. observed Y minus predicted Y — the vertical distance from a point to the line
c. The slope times the intercept
d. The p-value for the model

13. (T/F) The least-squares line minimizes the sum of the squared residuals, so positive and negative misses do not cancel out.

True / False

Diagnostic plots and assumptions

14. (MC) Which function gives you all four diagnostic plots for a fitted model paper_lm_model?

a. skim(paper_lm_model)
b. summary(paper_lm_model)
c. plot(paper_lm_model)
d. ggplot(paper_lm_model)

15. (Predict) For a model that fits well, the Residuals vs Fitted panel should look like:

a. A clear upward line
b. A random, flat, structureless band around the horizontal 0 line
c. A funnel that widens to the right
d. A U-shaped curve

16. (Predict) For a model that fits well, the Normal Q-Q panel should look like:

a. Points falling closely along the dashed diagonal line
b. Points forming a circle
c. A flat horizontal line
d. Points all stacked at zero

17. (T/F) The normality assumption of regression is about the model’s residuals, not the raw response variable.

True / False

18. (T/F) A high R² (e.g. 0.9999) means you no longer need to check the model’s assumptions.

True / False

19. (Fix) A student checks normality with shapiro.test(paper_df$area_cm2). What is the correct code?

a. shapiro.test(residuals(paper_lm_model))
b. shapiro.test(paper_df)
c. shapiro.test(paper_df$mass_g)
d. leveneTest(paper_lm_model)

20. (Fix) ★ A student concludes: “R² = 0.9999, so the model must be correct — no need to check assumptions.” What is wrong with that reasoning?

a. Nothing — high R² does guarantee a correct model
b. R² only measures how tightly points hug the line; it says nothing about linearity, equal variance, normality, or independence
c. R² should be negative
d. R² measures the slope, not the fit

predict() and intervals

21. (Fix) This errors with object 'mass_g' not found. Why?

new <- tibble(mass = 0.092)
predict(paper_lm_model, newdata = new)

a. The model was fit on a column named mass_g, so newdata must also have a column named mass_g, not mass
b. predict() cannot take newdata
c. tibble() should be data()
d. 0.092 is too small

22. (Fix) This throws object 'paper_lm_model' not found. What most likely happened?

a_intercept <- coef(paper_lm_model)[1]
b_slope <- coef(paper_lm_model)[2]

a. coef() is not a real function
b. The lm() line that creates paper_lm_model (and the line that loads paper_df) never ran first
c. [1] and [2] should be [0] and [1]
d. You must load library(lm)

23. (MC) Compared with a confidence interval from predict(), a prediction interval for a single new observation is:

a. Always narrower b. Always wider c. Exactly the same width d. Undefined

24. (Fix) predict() is called with interval = "confidence" when the student actually wanted the interval for a single new tracing. What should they use instead?

a. interval = "prediction"
b. interval = "none"
c. interval = 0.95
d. se.fit = TRUE

25. (T/F) ★ Using the calibration curve to predict area for a tracing with mass_g = 5.2 is fine, even though the calibration squares only ranged from 0.01 to 4.5 g.

True / False

26. (MC) Predicting outside the observed range of X is called ______, and it is risky because ______.

a. interpolation — the data are too dense there
b. extrapolation — there is no data to confirm the relationship still holds beyond the observed range
c. standardization — the units change
d. bootstrapping — it resamples

Correlation vs. causation, and reporting

27. (MC) Both flipper length and body mass in the penguins data were measured, not manipulated. Which framing is more appropriate?

a. Correlation is more appropriate; a regression is better justified when one variable is manipulated or is clearly the predictor used to generate predicted values
b. Regression is always correct regardless of how data were collected
c. Neither can be analyzed
d. Only a t-test is valid here

28. (MC) When reporting a regression result, which set of numbers should you include?

a. Just the R²
b. The F-statistic with both df, the p-value, R², and the regression equation
c. Just the slope
d. Only the p-value
