Quiz 06: Regression

Instructions

This quiz covers linear regression: fitting the calibration curve of paper area vs. mass with lm(), reading summary(), the four assumptions, and using predict() to convert a leaf tracing’s mass into a predicted area.

The quiz has four parts: A) general knowledge, B) predict the output, C) troubleshooting broken code, and D) open-ended / applied questions.

Grading: 28 questions × 1 point = 28 points total. Partial credit is available on code and open-ended questions.

Answer key (instructor copy — remove before distributing)

Q Type Answer
A1 Concept ~ means “is predicted by” / “modeled as a function of”; area_cm2 (left of ~) is the response, mass_g (right) is the explanatory variable
A2 MC B — the change in Y per 1-unit increase in X
A3 MC C — proportion of variation in Y explained by X
A4 Concept Residual = observed − predicted, \(e_i = Y_i - \hat{Y}_i\); the vertical distance from a point to the regression line
A5 T/F TRUE
A6 MC C — plot(paper_lm_model)
A7 Concept Confidence interval = precision of the mean Y at a given X; prediction interval = precision for a single new observation; prediction interval is wider
B1 Predict Positive slope (more mass = more area); R² should be near 1 because paper of uniform stock has constant area-per-gram (near-perfect linear relationship)
B2 Predict Two named values: (Intercept) ≈ 0.28 (the a) and mass_g ≈ 130.5 (the b, cm² per gram)
B3 Predict A tight, clearly linear, positively sloped cloud of points running from lower-left to upper-right, with little scatter around an implied line and no obvious curve or outliers
B4 Predict Band is narrowest near the middle of the mass range (near \(\bar{X}\)) and widest at the extremes (low and high mass) — predictions are most precise near the mean of X
B5 Predict Tests H₀: β = 0 (mass does not predict area); a p-value this small means we reject H₀ — mass is a statistically significant predictor of area
B6 Predict Predicted area: 12.29 cm² (130.5 × 0.092 + 0.28 = 12.29)
B7 Predict Panel 1: a random, flat, structureless cloud of points scattered around the horizontal 0 line with no curve or funnel shape; Panel 2: points falling closely along the dashed diagonal reference line
C1 Error Formula is backwards — response goes on the left of ~; should be lm(area_cm2 ~ mass_g, data = paper_df) since we want to predict area from mass
C2 Error newdata column is named mass but the model was fit on mass_g — predict() needs the exact column name; fix: new <- tibble(mass_g = 0.092)
C3 Error The normality assumption applies to the model’s residuals, not the raw response; fix: shapiro.test(residuals(paper_lm_model))
C4 Error The model was never fit (or the object name is misspelled); need paper_lm_model <- lm(area_cm2 ~ mass_g, data = paper_df) run first (and paper_df loaded before that)
C5 Error A high R² only describes how tightly the points fit the line — it says nothing about whether the assumptions (linearity, equal variance, normality, independence) hold. Assumptions must always be checked regardless of R²
C6 Error interval = "confidence" gives the interval for the mean, not a single new observation; fix: use interval = "prediction"
C7 Error This is extrapolation — predicting outside the range of X values used to fit the model; risky because there is no data to confirm the linear relationship still holds beyond the observed range
D1 Concept H₀: β = 0 (mass does not predict area / no linear relationship); Hₐ: β ≠ 0 (mass does predict area)
D2 Concept Linearity (Residuals vs Fitted, panel 1, should show no curve); Independence (study design, not testable from plot()); Equal variance (panels 1 & 3, spread of residuals should be constant); Normality of residuals (panel 2 Q-Q + shapiro.test(residuals(model)))
D3 Concept Not useless — R² = 0.45 means 45% of variation is explained, which is common and meaningful in ecological data; statistical significance (p-value) and strength of fit (R²) are separate — a real, significant relationship can still have a lot of unexplained scatter
D4 Concept Neither flipper length nor body mass was experimentally manipulated — both are outcomes of shared underlying biology, so no causal direction can be assigned; regression would be more appropriate if one variable were manipulated or clearly logically prior/predictive (e.g., using flipper length specifically to generate a predictive equation for body mass)
D5 Concept Paper of uniform stock has constant area-per-gram, so mass and area are (near) perfectly linearly related; the key assumption is that the leaf tracing is made on the same paper stock as the calibration squares, so the same equation applies
D6 Concept (1) F-statistic and both df, (2) p-value, (3) R², (4) the actual regression equation, (5) 95% CI for the slope
D7 Concept 180–220 mm falls within the observed range of flipper lengths used to fit the model; 100 mm or 300 mm falls outside that range (extrapolation), so there is no data to confirm the relationship stays linear there — predictions there are unsupported
