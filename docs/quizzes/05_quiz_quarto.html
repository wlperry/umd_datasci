Answer key (instructor copy — remove before distributing)

Q Type Answer
1 MC B — the recipe: title, author, output format
2 T/F FALSE — YAML is space-sensitive; mixing tabs and spaces (or a stray space) breaks it
3 Short YAML front matter, Markdown text, code chunks
4 MC B — ```{r}
5 Short `r expression` inside prose; better because the value is computed live and updates automatically if the data changes, instead of going stale like a typed number
6 Match 1–C, 2–E, 3–B, 4–D, 5–A
7 MC C — Ctrl/Cmd + Shift + K
8 Predict Only the result, 4.75 — code is hidden (echo: false) but the chunk still runs (eval: true)
9 Predict “# Introduction” becomes a large heading; “sunny” and “shady” render bold; the two - lines become a bulleted list
10 Predict Only the code is shown, formatted as an R chunk; nothing runs, so no table/output appears
11 Predict “Shady-side leaves averaged 7.8 g.”
12 Predict A table of contents, numbered section headings (1, 1.1, 2, …), and figures sized 6 in × 4 in
13 Predict Three files: a Word document (.docx), a web page (.html), and a PowerPoint (.pptx) — all from one .qmd
14 Predict No — cross-reference labels for figures must start with fig- (e.g. fig-leaf-plot); @fig-leaf-plot will not resolve to a label that is just leaf-plot
15 Error Two chunks share the label plot; rename them uniquely, e.g. plot-box and plot-mean-se
16 Error The author line’s value is fine but date: today is indented with an extra leading space, breaking the YAML key-value alignment; remove the stray space so all top-level keys start in the same column
17 Error The chunk that reads/creates tree_df (e.g. read_excel(...)) is missing or is below this chunk; move the data-loading chunk above it
18 Error library(tidyverse) was never loaded; add it in a chunk at the top of the document, before any chunk that uses %>% or filter()
19 Error The closing ``` fence is missing, so Quarto treats everything after it as still being inside the code chunk; add the closing fence right after the chunk’s R code
20 Error Missing space after the colon (format:docx instead of format: docx) — YAML requires a space between key: and its value
21 Error Typo in the object name — maen_shady should be mean_shady, matching exactly what was created in the earlier chunk
22 Concept A Quarto report recomputes every number and figure straight from the data on each render, so there is no hand-copying step to introduce typos or go stale when the data changes; a script + copy-paste workflow requires manually redoing every number and figure by hand
23 Concept echo: false for a polished report meant for a reader who wants results, not code (e.g. a lab report or manager); echo: true for a teaching handout or workbook where the reader needs to see and learn the code itself
24 Concept echo controls whether the code is displayed; eval controls whether the code actually runs. A student workbook sets echo: true, eval: false so learners see the exact code to type without it executing (and without needing the data available)
25 Concept Quarto runs chunks top to bottom in a fresh session, so any object used in a chunk must already exist; using data or a function before it is loaded/created gives an “object not found” or “could not find function” error
26 Concept List multiple formats in the YAML format: block (docx: default, html: default, pptx: default) and render once — Quarto builds all three from the same source file and code
27 Concept A copy-pasted number is frozen at the moment it was typed; if the data changes, that number is now wrong until someone remembers to retype it. An inline-code value recalculates every time the document is rendered, so it can never disagree with the current data
28 Concept Read which named chunk the error names; check that libraries and data are loaded in a chunk above it; check YAML spacing/tabs and that chunk labels are unique; fix the named chunk and render again, ideally rendering often so breaks are easy to isolate
