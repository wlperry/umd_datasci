Quiz 11 — One-Way ANOVA

comparing 3+ groups, assumptions, aov()/car::Anova(), and emmeans post-hoc — Palmer penguins

Author

Bill Perry

Published

September 24, 2026

Name: ______________________________ Date: ______________

Instructor note — this is a question bank, not the handout. Pick ~10 questions (spread across topics and types), delete the rest, this note, and the answer key. Tags: (MC) · (T/F) · (Predict) predict the output · (Fix) spot the mistake. ★ marks a harder question.

Data: penguins_df is the cleaned Palmer penguins data (Adelie, Chinstrap, Gentoo). The class model is mass_model <- lm(body_mass_g ~ species, data = penguins_df).

Why ANOVA, and the F-statistic

1. (MC) The ANOVA F-statistic is a ratio of:

a. within-group variance / between-group variance
b. between-group variance / within-group variance (signal / noise)
c. the largest group mean / the smallest
d. sample size / number of groups

2. (T/F) Running three separate t-tests to compare three groups pushes the overall (family-wise) false-positive rate above 0.05.

True / False

3. (MC) With 4 groups, how many pairwise t-tests would you need to compare every pair?

a. 3 b. 4 c. 6 d. 12

4. (MC) “Between-group variance” in a penguin body-mass ANOVA means:

a. How much individual penguins scatter within their own species
b. How far apart the three species means are
c. The measurement error of the scale
d. The number of species

5. (MC) “Within-group variance” means:

a. How far apart the species means are
b. How much individual penguins scatter around their own species’ mean
c. The total number of penguins
d. The difference between the heaviest and lightest species

The model

6. (MC) In lm(body_mass_g ~ species, data = penguins_df):

a. body_mass_g is the predictor and species is the response
b. species is the predictor and body_mass_g is the response
c. Both variables are predictors
d. Invalid — species must be numeric

7. (Fix) A student writes lm(species ~ body_mass_g, data = penguins_df) to test whether mass differs by species. What is wrong?

a. The formula is backwards — it should be lm(body_mass_g ~ species, data = penguins_df)
b. lm() cannot be used for ANOVA
c. penguins_df must be a matrix
d. Nothing is wrong

8. (MC) Why does the lecture prefer car::Anova(model, type = "II") over base anova(model) for the penguin data?

a. Anova() runs faster
b. The groups are unbalanced (different n per species), and Type II does not depend on variable order
c. anova() cannot handle a categorical predictor
d. Anova() automatically drops missing data

9. (Fix) Anova(mass_model, type = "II") errors with could not find function "Anova". Why?

a. library(car) was never loaded — capital Anova() lives in car
b. type must be "2"
c. mass_model is not a model
d. Anova() only works on two-way designs

10. (Fix) car::Anova(mass_model, type = "2") misbehaves. What is wrong with the type argument?

a. type must be a Roman numeral string: "I", "II", or "III"
b. type must be a number without quotes: 2
c. type should be "two"
d. Nothing — "2" is fine

11. (T/F) ★ With one predictor, Type I, II, and III ANOVA give the same F and p — but the lecture still builds the type = "II" habit now because the sums-of-squares type changes the answer once you have two or more (unbalanced) predictors.

True / False

Assumptions

12. (MC) The three assumptions of a one-way ANOVA are:

a. Independence, normality of residuals, equal variance across groups
b. Linearity, large sample, no outliers
c. Equal group sizes, integer data, no missing values
d. Random slope, random intercept, nesting

13. (MC) shapiro.test(residuals(mass_model)) checks:

a. Equal variance across species
b. Normality of the model’s residuals
c. Whether the F-test is significant
d. Which species differ

14. (Fix) shapiro.test(mass_model) runs but does not check what the student thinks. What is wrong?

a. It is being run on the model object, not its residuals; use shapiro.test(residuals(mass_model))
b. shapiro.test() needs a formula
c. It should be leveneTest()
d. Nothing is wrong

15. (Fix) leveneTest(species ~ body_mass_g, data = penguins_df) is written backwards. What should it be?

a. leveneTest(body_mass_g ~ species, data = penguins_df) — numeric response ~ grouping factor
b. leveneTest(penguins_df$species)
c. leveneTest(body_mass_g + species)
d. It is already correct

16. (Predict) leveneTest(body_mass_g ~ species, data = penguins_df) returns p = 0.34. You:

a. Switch to Welch’s ANOVA — the variances differ
b. Proceed with the classic ANOVA — the variances are not significantly different
c. Stop — ANOVA is not valid
d. Run a t-test instead

17. (Fix) A student fits the model on penguins (raw) instead of penguins_df (cleaned). What is the risk?

a. None — lm() handles it identically
b. Rows with missing body_mass_g/species are silently dropped, so counts and plots may not match the model; the lecture drops NA explicitly for a clean, documented dataset
c. lm() will refuse to run
d. The species names change

18. (T/F) ★ With ~340 penguins, Shapiro-Wilk can flag tiny, harmless departures from normality as “significant,” so you should trust the Q-Q plot more in that situation.

True / False

Predicting output

19. (Predict) penguins_df %>% count(species) prints:

a. 1 row, 1 column
b. 3 rows (Adelie, Chinstrap, Gentoo) with columns species and n
c. 342 rows
d. A single number

20. (Predict) A boxplot of body_mass_g by species with jittered points looks like:

a. One box for all penguins combined
b. Three boxes; Gentoo clearly higher/heavier than Adelie and Chinstrap, which overlap more with each other
c. A scatterplot with a trend line
d. A histogram

21. (Predict) par(mfrow = c(2, 2)); plot(mass_model) produces, in order:

a. Residuals vs Fitted, Normal Q-Q, Scale-Location, Residuals vs Leverage
b. Histogram, boxplot, scatterplot, bar chart
c. Four identical scatterplots
d. The ANOVA table four times

22. (Predict) The ANOVA Pr(>F) comes back far below 0.001. What can you conclude?

a. All three species differ from each other
b. At least one species mean differs from the others — but not which ones
c. Gentoo is the heaviest
d. The residuals are normal

23. (Predict) mass_emm <- emmeans(mass_model, pairwise ~ species) then mass_emm$contrasts is printed. How many rows?

a. 1 b. 2 c. 3 (Adelie–Chinstrap, Adelie–Gentoo, Chinstrap–Gentoo) d. 9

24. (Predict) A means plot has one point per species and error bars showing the 95% CI of each estimated mean. Two error bars that overlap a lot would suggest:

a. Those two species’ means are not clearly distinguishable
b. Those two species definitely differ
c. The model failed
d. The sample size is too large

Post-hoc: emmeans and compact letters

25. (MC) emmeans(model, pairwise ~ species) is used to:

a. Test equal variance across groups
b. Give the classic ANOVA F table
c. Run post-hoc pairwise comparisons (which groups differ)
d. Test normality of the residuals

26. (T/F) Tukey-adjusted emmeans pairwise comparisons already correct for multiple comparisons, so the family-wise error rate stays at 0.05 without extra work.

True / False

27. (Fix) mass_emm <- emmeans(mass_model, ~ species) then mass_emm$contrasts fails. What was forgotten?

a. pairwise ~ species — without pairwise, emmeans() returns only estimated means, no $contrasts
b. library(emmeans)
c. data = penguins_df
d. type = "II"

28. (Fix) multcomp::cld(mass_emm, Letters = letters) errors. What should be passed instead?

a. mass_emm$emmeans — cld() needs the emmeans grid, not the whole list
b. mass_model
c. penguins_df
d. residuals(mass_model)

29. (MC) A compact letter display assigns Adelie → “a”, Chinstrap → “a”, Gentoo → “b”. This means:

a. All three species differ
b. Adelie and Chinstrap do not differ; Gentoo differs from both
c. No species differ
d. Gentoo is missing data

Hypotheses and reporting

30. (MC) H₀ and Hₐ for a one-way ANOVA on penguin body mass are:

a. H₀: μ_Adelie = μ_Chinstrap = μ_Gentoo ; Hₐ: at least one species mean differs
b. H₀: all species means differ ; Hₐ: all species means are equal
c. H₀: the residuals are normal ; Hₐ: they are not
d. H₀: Gentoo is heaviest ; Hₐ: Gentoo is lightest

31. (MC) Which is a prediction, not a hypothesis?

a. H₀: all three species means are equal
b. Hₐ: at least one species mean differs
c. “I expect Gentoo will be the heaviest because they look bigger”
d. α = 0.05

32. (MC) The ANOVA gives p < 0.001. Without a post-hoc test, you cannot conclude:

a. That at least one species mean differs
b. Which specific species differ from each other
c. That the F-statistic is large
d. That the result is unlikely under H₀

33. (T/F) A significant ANOVA F-test tells you that the groups differ, not which ones.

True / False

34. (MC) Which is a correctly formatted ANOVA results sentence?

a. “Body mass differed significantly among the three penguin species (one-way ANOVA: F(2, 339) = 343.6, p < 0.001). Tukey-adjusted comparisons showed all three species differed except Adelie and Chinstrap, with Gentoo heaviest.”
b. “The ANOVA was significant, p = 0.000, so Gentoo is heaviest.”
c. “There was a difference (F = 343.6).”
d. “p < 0.001 proves the species are different everywhere.”
