Question 10 · Predict / short answer — compact letters

In a compact letter display, Adelie gets a, Chinstrap gets a, and Gentoo gets b. Which species are statistically different from each other, and which are not?

Answer key (instructor copy — remove before distributing)

Q Type Answer
1 T/F TRUE — 3 tests at α = 0.05 gives ~14% family-wise error
2 MC B — between ÷ within (signal ÷ noise)
3 Concept H₀: μ₁ = μ₂ = μ₃ (all species means equal); Hₐ: at least one differs
4 Match 1–B, 2–D, 3–A, 4–E, 5–C
5 Code See below
6 Error library(car) is missing; lowercase anova() compares models (Type I), capital Anova() gives the Type II/III table
7 MC B — at least one differs; post-hoc says which
8 Code emmeans(mass_model, pairwise ~ species)
9 T/F TRUE
10 Concept Gentoo (b) differs from both Adelie and Chinstrap (a); Adelie and Chinstrap share a letter, so they do not differ

Q5 model answer

mass_model <- lm(body_mass_g ~ species, data = penguins_df)
car::Anova(mass_model, type = "II")
