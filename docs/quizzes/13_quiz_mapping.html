Answer key (instructor copy — remove before distributing)

Q Type Answer
1 T/F TRUE
2 MC B — EPSG:4326 (WGS84)
3 Match 1–B, 2–D, 3–C, 4–A
4 Code st_as_sf(bigfoot_df, coords = c("longitude", "latitude"), crs = 4326)
5 Error coords must be x first, then y = c("longitude", "latitude"); they swapped them
6 Code filter(!is.na(latitude), !is.na(longitude)) before st_as_sf()
7 Code See below
8 Predict Key mismatch ("Washington" ≠ "washington"); fix with str_to_lower() so both keys match
9 MC B
10 T/F TRUE
