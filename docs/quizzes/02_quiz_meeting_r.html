Answer key (instructor copy — remove before distributing)

Q Type Answer
1 Concept <- stores the value on the right into the name on the left; = is avoided so assignment stays visually distinct from naming arguments inside function calls
2 MC C — leaf_weight_g; 3rd_sample starts with a number, my.leaf.data uses dots (avoid), mean shadows a built-in function
3 Concept Package = installed toolbox (install once with install.packages()); library = loading it for the session (library(readxl) / install.packages("readxl"))
4 MC B — read_csv() needs library(tidyverse)
5 Concept “Take tree_df, THEN show the first 3 rows” — the pipe feeds the result on its left into the function on its right
6 MC B — mixing a number and a string coerces the whole vector to character
7 Concept Console = scratch paper, run once and forgotten; script = saved, re-runnable record — required so work is reproducible
8 Predict 14, then 4 (length of y)
9 Predict 20, then "index" "side" "weight_g" "width_cm" "height_cm"
10 Predict 3.14 — rounded to 2 decimal places
11 Predict class(a) = "numeric", class(b) = "character", class(c_vec) = "numeric" (TRUE becomes 1)
12 Describe x-axis = side (2 categories: shady, sunny), y-axis = leaf weight (g); two boxes (one per side) with individual tomato-colored jittered points scattered around each box, titled “Sunny vs. shady leaves”
13 Predict side shows as <chr>; if weight_g were accidentally text it would show as <chr> with values like "4", "3" instead of <dbl> — a sign a stray character snuck into the spreadsheet
14 Predict 2 panels stacked in 1 column (one per level of side), each a histogram of weight_g for that side
15 Error library(readxl) is missing — install.packages() only downloads the package, library() must be called every session to activate its functions
16 Error Text values need quotes — c("sunny", "shady"); without quotes R looks for objects named sunny/shady and errors
17 Error Fix 1: missing + at the end of the first line connecting ggplot() to geom_boxplot(); Fix 2: missing comma after x = "Side of tree" inside labs()
18 Concept install.packages() re-downloads the package every run, which is slow and unnecessary — install once in the Console, and only keep library() calls in the script
19 Error ggsave() expects the filename as the first argument; correct call is ggsave("figures/leaf_weight.png", plot = weight_plot, dpi = 300)
20 Error R is case-sensitive — the column is weight_g, not Weight_g
21 Error Wrong function for the file type — a .csv needs read_csv(), not read_excel()
22 Concept Separating raw data, code, and outputs keeps files organized, prevents accidentally overwriting raw data, and makes it easy for anyone (including future-you) to find things
23 Concept Keeping raw data untouched means you can always retrace your steps and re-run the analysis from scratch; overwriting it destroys the ability to verify or redo the work
24 Concept Catches wrong row/column counts, columns read in as the wrong type (e.g. numbers read as <chr>), unexpected NAs, and typos in column names — cheap to check, expensive to discover later
25 Concept A consistent suffix convention makes it instantly clear what kind of object you’re looking at (a table vs. a plot vs. a fitted model) without having to trace back to where it was created
26 Concept The default resolution (72 dpi) looks blurry when printed or placed in a report/poster; 300 dpi is publication quality
27 Concept A boxplot+jitter shows the distribution (median, spread, individual values) of a continuous variable within each discrete group — a scatter plot needs two continuous axes and doesn’t summarize a categorical grouping well
28 Concept (1) Read the error message carefully — it usually names the line/problem; (2) check the usual suspects — libraries loaded, spelling, missing ) or +; (3) look up ?function_name or the tidyverse cheat sheets before asking for help
