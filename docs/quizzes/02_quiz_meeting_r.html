Quiz 02 — Meeting R

R basics, projects, packages, the pipe, and your first plot

Author

Bill Perry

Published

September 14, 2026

Name: ______________________________ Date: ______________

Instructor note — this is a question bank, not the handout. Pick ~10 questions (spread across topics and types), delete the rest, this note, and the answer key. Each question is tagged: (MC) multiple choice · (T/F) true/false · (Y/N) yes/no · (Predict) predict the output · (Fix) spot the mistake. ★ marks a harder question.

Data: leaf_df has one row per leaf, columns shade ("sunny"/"shady"), mass_g, petiole_mm, thickness_mm, paper_mass_g.

The assignment operator <-

1. (MC) What does <- do in leaf_df <- read_excel("data/leaves.xlsx")?

a. Tests whether the two sides are equal
b. Stores the value on the right under the name on the left
c. Prints the data to the screen
d. Installs a package

2. (MC) Why does this course use <- for assignment instead of =?

a. = does not work in R
b. <- runs faster
c. It keeps assigning an object visually separate from setting an argument inside a function() call
d. = can only be used once per script

3. (T/F) In round(x = 3.14159, digits = 2), the = signs are creating two new objects called x and digits.

True / False

4. (T/F) mass <- 5 and 5 -> mass both store the number 5 under the name mass.

True / False

5. (Predict) After running x <- 4 and then y <- x + 6, what prints when you run y?

a. 4 b. 6 c. 10 d. nothing prints

6. (Fix) A student writes read_excel("data/leaves.xlsx") <- leaf_df and gets an error. What is wrong?

a. The name and the value are on the wrong sides — it should be leaf_df <- read_excel("data/leaves.xlsx")
b. read_excel() needs library(tidyverse)
c. <- should be ==
d. Nothing is wrong

The pipe %>%

7. (MC) The best plain-English reading of leaf_df %>% glimpse() is:

a. “glimpse leaf_df or something”
b. “take leaf_df, then glimpse it”
c. “make a new object called glimpse”
d. “divide leaf_df by glimpse”

8. (MC) The pipe %>% takes the result on its left and:

a. hands it to the function on its right as that function’s first input
b. saves it to a file
c. deletes it
d. prints it in red

9. (T/F) %>% and the native pipe |> behave the same way for everything in this course.

True / False

10. (T/F) The pipe works only after a package such as the tidyverse has been loaded.

True / False

11. (Predict) leaf_df has 24 rows. What does leaf_df %>% nrow() return?

a. 1 b. 24 c. the whole table d. an error

12. (Fix) A student writes glimpse() %>% leaf_df and it errors. Why?

a. The pipe feeds the left side into the right side, so it should be leaf_df %>% glimpse()
b. glimpse() is not a real function
c. You cannot pipe a data frame
d. Nothing is wrong

Packages and libraries

13. (MC) Which statement is correct?

a. install.packages() must be re-run every time you open R
b. library() downloads the package from the internet
c. install.packages() puts the package on your computer once; library() loads it into each new session
d. “package” and “library” mean exactly the same thing

14. (MC) You installed readxl last week. Which line lets you call read_excel() today?

a. install.packages("readxl")
b. library(readxl)
c. load("readxl")
d. read_excel(readxl)

15. (MC) read_csv() comes from which package?

a. readxl
b. janitor
c. the tidyverse (readr)
d. base R — no package needed

16. (T/F) read_excel() needs library(readxl), but read_csv() comes with library(tidyverse).

True / False

17. (T/F) It is good practice to keep install.packages() lines at the top of a script and run them every class.

True / False

18. (Fix) This throws could not find function "read_excel". What is the fix?

install.packages("readxl")
leaf_df <- read_excel("data/leaves.xlsx")

a. Reinstall R
b. Add library(readxl) before the read_excel() line
c. Change read_excel to read.excel
d. Move install.packages("readxl") to the bottom

Reading data and file paths

27. (MC) A classmate emails you a file called leaves.csv. Which line reads it into R?

a. read_excel("leaves.csv")
b. read_csv("leaves.csv")
c. read_csv("leaves.xlsx")
d. library("leaves.csv")

28. (T/F) In a project, read_csv("data/leaves.csv") is a relative path that keeps working if you move the whole project folder to another computer.

True / False

29. (Fix) read_csv("Data/Leaves.CSV") throws “does not exist”, but data/leaves.csv is right there. Why?

a. File paths are case-sensitive
b. read_csv() cannot read .csv files
c. You need library(readr)
d. .csv file names must be capitalized

30. (MC) read_excel("data/temps.csv") after library(readxl) fails. Best fix?

a. read_csv("data/temps.csv") — use the CSV reader for a .csv file
b. Re-spell library(readxl)
c. Add a ~ to the path
d. Nothing — this works

Vectors and data types

31. (Predict) After y <- c(2, 4, 6, 8), what does length(y) return?

a. 4 b. 8 c. 20 d. c(2, 4, 6, 8)

32. (Predict) What does round(3.14159, 2) return?

a. 3 b. 3.14 c. 3.142 d. 3.14159

33. (Predict) ★ What does class(c(1, 2, 3, "a")) return?

a. "numeric" — R ignores the "a"
b. "character" — one text value forces the whole vector to text
c. "logical"
d. an error — you cannot mix numbers and text

34. (T/F) A single vector can hold numbers and text at the same time, with each value keeping its own type.

True / False

35. (Fix) shade <- c(sunny, shady) throws object 'sunny' not found. The fix is:

a. shade <- c("sunny", "shady") — text values need quotes
b. shade <- c(sunny shady)
c. shade <- (sunny, shady)
d. Load the tidyverse first

Your first ggplot

36. (MC) What does this code produce?

ggplot(leaf_df, aes(x = shade, y = mass_g)) +
  geom_boxplot()

a. A scatterplot of mass vs. shade with a trend line
b. Two boxplots side by side — one for "shady", one for "sunny" — with mass on the y-axis
c. A histogram of leaf mass
d. An error, because a word cannot go on the x-axis

37. (Predict) shade contains only "sunny" and "shady". How many boxes does the plot above draw?

a. 1 b. 2 c. 24 d. 0

38. (T/F) In ggplot, layers are joined with +, not with %>%.

True / False

39. (Fix) This errors. What is wrong?

ggplot(leaf_df, aes(x = shade, y = mass_g))
  geom_boxplot()

a. geom_boxplot() needs the data inside its parentheses
b. The first line is missing a + at the end to connect it to geom_boxplot()
c. aes() should be aesthetic()
d. Nothing is wrong

40. (Fix) ★ This code has two mistakes. Which option lists both?

ggplot(leaf_df, aes(x = shade, y = mass_g))
  geom_boxplot() +
  labs(x = "Side of tree"
       y = "Leaf mass (g)")

a. Missing + after aes(...); missing comma after "Side of tree" inside labs()
b. ggplot should be gg_plot; geom_boxplot should be geom_box()
c. aes() needs quotes around shade; labs() should be labels()
d. Missing library(ggplot2); the file path is wrong

Case sensitivity and the project workflow

41. (MC) leaf_df$Mass_g returns NULL even though a mass column exists. Why?

a. You need library(dplyr)
b. The column is mass_g (lowercase) — R is case-sensitive
c. $ should be %>%
d. The data frame is empty

42. (T/F) If glimpse(leaf_df) shows mass_g as <chr> instead of <dbl>, a stray letter or symbol probably got into that column in the spreadsheet.

True / False

43. (MC) Why keep data/, scripts/, and figures/ in separate sub-folders?

a. R will not run otherwise
b. It keeps the raw data safe from accidental edits and makes every file easy to find
c. It makes scripts run faster
d. There is no real reason

44. (T/F) When you find a problem in the data, the right move is to open the raw data file and fix it there.

True / False

45. (MC) Your code throws an error you do not recognize. Best first step?

a. Delete the script and start over
b. Read the error message — it usually names the line and the problem
c. Email the professor immediately
d. Restart the computer
