Data: leaf_df has shade ("sunny"/"shady") and mass_g. The class model is leaf_ttest_model <- t.test(mass_g ~ shade, data = leaf_df, var.equal = FALSE).

Hypotheses vs. predictions

1. (MC) Which of these is a prediction, not a statistical hypothesis?

a. H₀: the mean mass is the same on both sides
b. Hₐ: the mean mass differs between sides
c. “I think shady leaves will be heavier because they are bigger to catch more light”
d. α = 0.05

2. (T/F) You should write H₀ and Hₐ down before looking at the data or running the test.

True / False

3. (T/F) A biological prediction gives a direction (“shady will be heavier”); the H₀/Hₐ pair is the formal statement the test actually evaluates.

True / False

4. (MC) We use a two-tailed test even though we predicted shady leaves would be heavier. Why?

a. Two-tailed tests are easier to compute
b. A two-tailed test can detect a difference in either direction and is more conservative
c. R cannot run one-tailed tests
d. Two-tailed tests do not need a significance level

5. (T/F) ★ Running a two-tailed test, seeing p = 0.08, then switching to the one-tailed test that gives p = 0.04 is a legitimate way to analyze the data.

True / False

The t.test() call

6. (MC) In t.test(mass_g ~ shade, data = leaf_df), which is true?

a. mass_g is the grouping variable and shade is the response
b. shade is the grouping variable and mass_g is the response
c. Both are grouping variables
d. This is invalid — shade must be numeric

7. (MC) Which argument makes t.test() run Welch’s version?

a. alternative = "two.sided"
b. var.equal = FALSE
c. conf.level = 0.95
d. paired = TRUE

8. (Fix) A student writes t.test(shade ~ mass_g, data = leaf_df) and gets an error. The fix is:

a. t.test(mass_g ~ shade, data = leaf_df) — response on the left of ~, group on the right
b. t.test(shade == mass_g, data = leaf_df)
c. t.test(leaf_df$shade, leaf_df$mass_g, equal = TRUE)
d. Add var.equal = TRUE

9. (Fix) A student wants a 99% confidence interval and writes conf.level = 99. What should it be?

a. conf.level = 0.99 — it is a proportion between 0 and 1
b. conf.level = "99%"
c. conf.int = 99
d. alpha = 99

10. (Fix) This throws a syntax error. What is wrong?

leaf_df %>%
  filter(shade == "sunny") %>%
  pull(mass_g)
  shapiro.test()

a. pull() should be select()
b. The last line is missing a %>% after pull(mass_g)
c. shapiro.test() needs a formula
d. filter() must come last

Assumptions

11. (MC) Which package provides leveneTest()?

a. tidyverse b. readxl c. car d. base R — no package needed

12. (T/F) Welch’s t-test requires the two groups to have equal variance.

True / False

13. (T/F) The null hypothesis for the Shapiro-Wilk test is “the data are normal,” so a large p-value (e.g. 0.32) is what lets you proceed with the t-test.

True / False

14. (T/F) The t-test’s normality assumption applies within each group, so you check sunny and shady separately, not the pooled column.

True / False

15. (T/F) Independence of observations comes from the study design and cannot be confirmed with a statistical test after the fact.

True / False

16. (Fix) This errors with could not find function "leveneTest". What is wrong?

leveneTest(mass_g ~ shade, data = leaf_df)

a. The formula is backwards
b. library(car) was never loaded
c. leveneTest() needs numeric groups
d. leaf_df does not exist

17. (Fix) A student runs shapiro.test(leaf_df$mass_g) on the whole column at once. What is wrong with that?

a. Nothing — that is the correct check
b. Normality for a t-test is about each group, so you must test sunny and shady separately
c. shapiro.test() only works on data frames
d. You must use leveneTest() instead

18. (MC) ★ Levene’s test returns p = 0.02 (variances differ), but a student runs t.test(mass_g ~ shade, data = leaf_df, var.equal = TRUE). What is the safer choice?

a. Keep var.equal = TRUE — it does not matter
b. Use var.equal = FALSE (Welch’s), which does not assume equal variance
c. Stop — you cannot run a t-test at all
d. Switch to a one-tailed test

Predicting output and decisions

19. (MC) A p-value tells you:

a. The probability that the null hypothesis is true
b. The probability of seeing a difference at least this large if the null hypothesis were true
c. The size of the difference between the two groups
d. Whether your sample size was large enough

20. (Predict) shapiro.test() on the sunny group returns p = 0.32. What do you conclude?

a. Reject normality — do not run the t-test
b. Fail to reject normality — the normality assumption is OK, proceed
c. The groups have equal variance
d. The means are equal

21. (Predict) leveneTest(mass_g ~ shade, data = leaf_df) returns p = 0.61. What does this tell you?

a. The variances differ significantly — switch tests
b. The variances are not significantly different; either way this course uses Welch’s
c. The means are different
d. The data are not normal

22. (Predict) leaf_ttest_model returns t = 1.15, df = 21.3, p = 0.26, with a 95% CI for the difference in means of [-0.05, 0.18]. At α = 0.05, the decision is:

a. Reject H₀ — the sides differ
b. Fail to reject H₀ — p > 0.05 and the CI includes 0
c. Reject H₀ — the CI includes 0
d. Cannot decide without the raw data

23. (Predict) ★ Suppose instead a t-test returns t = 9.98, df = 17.4, p < 0.001, 95% CI [3.2, 4.8]. Which single statement is the correct interpretation?

a. There is a 0.1% chance the null hypothesis is true
b. Reject H₀: the group means differ, and 0 is not a plausible value for that difference
c. Fail to reject H₀, because the CI does not contain the mean
d. The result proves shady leaves are heavier in every tree everywhere

24. (Predict) With p_val <- 0.26 and alpha <- 0.05, what prints?

if (p_val < alpha) {
  cat("Decision: REJECT H0\n")
} else {
  cat("Decision: FAIL TO REJECT H0\n")
}

a. Decision: REJECT H0
b. Decision: FAIL TO REJECT H0
c. Both lines print
d. An error

25. (Predict) Given leaf_ttest_model$statistic = 1.15 and leaf_ttest_model$p.value = 0.264, what text does this build?

paste0("Welch's t-test: t = ", round(leaf_ttest_model$statistic, 2),
       ", p = ", signif(leaf_ttest_model$p.value, 2))

a. "Welch's t-test: t = 1.15, p = 0.26"
b. "Welch's t-test: t = 1, p = 0.3"
c. "Welch's t-test: t = 1.15, p < 0.001"
d. "Welch's t-test: t = 1.150, p = 0.264000"

26. (MC) Describe the shape of this result:

leaf_df %>%
  group_by(shade) %>%
  summarize(n = sum(!is.na(mass_g)),
            mean_mass = mean(mass_g, na.rm = TRUE))

a. 1 row, 2 columns
b. 2 rows, 3 columns (shade, n, mean_mass)
c. 24 rows, 3 columns
d. 3 rows, 2 columns

27. (MC) What does this code produce?

leaf_df %>%
  ggplot(aes(x = shade, y = mass_g, fill = shade)) +
  geom_boxplot(alpha = 0.5, outlier.shape = NA) +
  geom_point(position = position_jitter(width = 0.15), alpha = 0.6) +
  theme(legend.position = "none")

a. A single boxplot of all leaves combined
b. Two boxplots (sunny, shady) with the raw points jittered on top and no legend
c. A scatterplot of mass vs. shade
d. A histogram split by shade

Reporting

28. (T/F) “Fail to reject H₀” is the same thing as “we proved there is no difference.”

True / False

29. (T/F) A p-value should never be reported as p = 0.000; write p < 0.001 instead.

True / False

30. (MC) Which is a correctly formatted results sentence for a non-significant result?

a. “Leaf mass did not differ significantly between sunny and shady leaves (Welch’s t-test: t(21.3) = 1.15, p = 0.26).”
b. “The t-test failed, p = 0.26, so the leaves are the same.”
c. “p = 0.26 proves there is no difference anywhere.”
d. “t = 1.15 so shady leaves are heavier.”
