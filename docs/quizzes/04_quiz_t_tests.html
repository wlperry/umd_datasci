Answer key (instructor copy — remove before distributing)

Q Type Answer
1 MC C — car
2 T/F FALSE — Welch’s does not require equal variance; that’s the point of it
3 Concept The probability of seeing a difference this large (or larger) if H₀ were true — a small p means the result is unlikely to be due to chance alone
4 MC B — var.equal = FALSE
5 Concept weight_g is the response/measured variable; side is the grouping variable (sunny/shady)
6 T/F TRUE
7 MC B — two-tailed is more conservative and detects a difference in either direction
8 Predict 2 rows (one per side), columns side, n, mean_wt
9 Predict Boxplots for shady and sunny with median line and IQR box, overlaid jittered raw points, no legend (colors mapped to fill but redundant with x-axis)
10 Predict p > 0.05 → fail to reject normality → proceed with t-test
11 Predict p > 0.05 → variances not significantly different; still use Welch’s regardless
12 Predict p < 0.001 and CI excludes zero → reject H₀; shady leaves are significantly heavier than sunny leaves
13 Predict Prints Decision: REJECT H0 since 0.002 < 0.05
14 Predict "Welch's t-test: t = 9.98, p = 1.2e-06"
15 Error library(car) was never loaded — leveneTest() lives in car, not base R
16 Error Formula is backwards — response goes on the left of ~, grouping variable on the right: t.test(weight_g ~ side, data = tree_df)
17 Error Using the pooled-variance test when variances differ risks an unreliable p-value (inflated Type I error); should use var.equal = FALSE (Welch’s)
18 Error Testing the pooled column ignores that the t-test’s normality assumption applies within each group — must filter() by side and test each group separately
19 Error A p-value is never exactly 0 — report p < 0.001 instead of p = 0.000
20 Error Missing %>% before shapiro.test() — should be ... %>% pull(weight_g) %>% shapiro.test()
21 Error conf.level must be a proportion between 0 and 1 — should be conf.level = 0.99
22 Concept A prediction is a plain-language biological guess about direction; H₀/Hₐ are formal, testable statistical statements (often two-tailed) that let us apply a decision rule (reject / fail to reject)
23 Concept Independence (study design, not testable statistically); Normality (histogram + shapiro.test() per group); Equal variance (leveneTest() — informational only, since we use Welch’s regardless)
24 Concept Welch’s performs almost identically to the standard test when variances are equal, but protects against inflated Type I error when they are not — so it’s a safe default either way, with no real cost
25 Concept Prevents “HARKing” (Hypothesizing After Results are Known) — committing to a hypothesis first keeps the analysis honest and prevents cherry-picking a direction after seeing the data
26 Concept Low power means the test often fails to detect real non-normality when it exists (misses it, not over-flags it) — so a “pass” from Shapiro-Wilk with small n is weak evidence; the histogram must be checked too
27 Concept It’s the range of plausible values for the true population difference in means; if the interval excludes zero, zero is not a plausible value for the difference, consistent with rejecting H₀ at α = 0.05
28 Applied See model answer below

Q28 model answer

“Shady-side leaves were significantly heavier than sunny-side leaves (Welch’s t-test: t(17.4) = 9.98, p < 0.001). Mean ± SE: shady = 7.80 ± 0.31 g, sunny = 3.80 ± 0.28 g.”
