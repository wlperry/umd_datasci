Question 10 · Short answer — why reorder?

In one sentence, why is reordering a factor by a value (not alphabetically) usually better for a reader?

Answer key (instructor copy — remove before distributing)

Q Type Answer
1 T/F TRUE
2 MC B — alphabetical by default
3 Match 1–C, 2–A, 3–E, 4–B, 5–D
4 Predict 1 2 3 — as.numeric() returns the integer level codes, not the labels
5 Code See below
6 Error x <- as.numeric(as.character(years)) — convert to character first
7 Code mutate(species = fct_relevel(species, "Gentoo"))
8 MC A — filter drops rows not levels; fct_drop() clears the empty level
9 T/F FALSE — forcats loads with library(tidyverse)
10 Concept Ordering by value makes the ranking instantly readable; alphabetical order carries no meaning

Q5 model answer

penguins_df %>%
  mutate(species = fct_reorder(species, body_mass_g, .fun = median))
