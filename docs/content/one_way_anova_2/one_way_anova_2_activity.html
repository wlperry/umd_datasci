Part A1 · Same data, same model

▶ Run this at the top of your script:

library(tidyverse)      # dplyr + ggplot2
library(palmerpenguins) # the penguins data
library(car)            # leveneTest(), Anova()
library(emmeans)        # pairwise follow-up tests

▶ Run this:

penguins_df <- penguins %>%
  drop_na(body_mass_g, species)

mass_model <- lm(body_mass_g ~ species, data = penguins_df)

Anova(mass_model)

That is the F(2, 339) = 343.6, p < 0.001 we reported last time — without checking whether we were allowed to.

Every script starts from the raw data. Nothing today depends on objects left in last lecture’s session.

🧩 Set 2 — The assumptions

A one-way ANOVA assumes (1) the observations are independent — a design question, no R function can rescue it; (2) the residuals are normally distributed; (3) the groups have equal variance.

Part A2 · Normality is about the residuals

A residual is one bird’s miss: its mass minus its species’ mean.

▶ Run this:

head(residuals(mass_model), 4)

ANOVA does not need the raw masses to be normal — pooled across three species with different means they are not even supposed to be. It needs the misses to be normal.

Part A3 · plot(model) — the same four panels

🔮 Predict first: with ~340 penguins, will the Normal Q-Q panel track the line tightly?

▶ Run this:

par(mfrow = c(2, 2))
plot(mass_model)
par(mfrow = c(1, 1))
Panel Name What it checks
1 Residuals vs Fitted three vertical stripes — with a categorical X there are only three fitted values. Normal, not a problem
2 Normal Q-Q the normality check — points on the line
3 Scale-Location are the stripe heights equal? (assumption 3 by eye)
4 Residuals vs Leverage is one point in charge?

✏️ QA1: Do the points in panel 2 track the dashed line? Do the three stripes in panels 1 and 3 look like they have the same height?

Part A4 · Shapiro-Wilk, as the backup

▶ Run this:

shapiro.test(residuals(mass_model))
  • H₀: the residuals are normal. p > 0.05 → no evidence against normality.
  • Note residuals(mass_model), not penguins_df$body_mass_g. Shapiro on the raw masses is a different, wrong test.

⚠️ Watch out! At n = 342, Shapiro-Wilk flags tiny departures. A p just above 0.05 is not “barely passed” — it is a very sensitive test nearly flagging a QQ plot that looks fine. Trust the plot; use the test as a second opinion.

✏️ QA2: Shapiro-Wilk W and p. Does that agree with what you saw in panel 2?

Part A5 · Equal variance, by eye first

▶ Run this:

penguins_df %>%
  group_by(species) %>%
  summarize(n    = n(),
            mean = mean(body_mass_g),
            sd   = sd(body_mass_g))

✏️ QA3: Write the three sds down. How many times bigger is the largest than the smallest? Rule of thumb: equal n makes ANOVA forgiving about unequal variance, unequal n does not — which case are we in?

Part A6 · Levene’s test

🔮 Predict first: given those sds, will Levene call the variances equal (p > 0.05) or unequal?

▶ Run this:

leveneTest(body_mass_g ~ species, data = penguins_df)

H₀: all groups have equal variance.

✏️ QA4: Levene’s F and p. Equal variances, Y / N? So is the classic ANOVA from A1 allowed, Y / N?

Important

This is not a mistake in the activity. It is what this data set does. Real data does this constantly.

Part A7 · Welch’s ANOVA — when variances are unequal

▶ Run this:

oneway.test(body_mass_g ~ species,
            data = penguins_df,
            var.equal = FALSE)

The fractional denominator df is Welch’s signature — it is the same correction as Welch’s t-test, which is already what t.test() does by default.

✏️ QA5: Fill in both tests — the classic Anova() F and p, and the Welch oneway.test() F and p. Which one do you report, and why that one?

✏️ QA6: Both agree here, so the violated assumption cost us nothing. Is that a reason to skip the check next time? Explain.

💡 Key idea: check → decide → test → report the test you decided on. Not “run everything and report the smallest p.”

🧩 Set 3 — The follow-up tests

The F-test said “at least one species differs.” It cannot tell you which — and on the boxplot two of the three species looked almost identical.

Part A8 · Pairwise comparisons with emmeans

🔮 Predict first: will all three species differ from each other, or will two be tied? Commit before you run it.

emmeans does the three comparisons and adjusts the p-values so the family-wise error rate stays at 0.05. The adjustment for all-pairs comparisons is Tukey’s HSD. The p-values printed are already adjusted — compare them with 0.05 directly, do not divide anything.

▶ Run this:

mass_emm <- emmeans(mass_model, pairwise ~ species)

mass_emm$contrasts

emmeans(model, pairwise ~ species) returns a list of two things. Here is the other half — the group means:

▶ Run this:

mass_emm$emmeans

✏️ QA7: Record each comparison — Adelie vs Chinstrap, Adelie vs Gentoo, Chinstrap vs Gentoo. p, and different Y / N.

✏️ QA8: The overall ANOVA p was below 0.001. Explain, in your own words, how that is consistent with two of the three species not differing at all.

Part A9 · Compact letter display

▶ Run this:

multcomp::cld(mass_emm$emmeans, Letters = letters)
  • Same letter → not shown to be different
  • Different letters → significantly different

This is the notation you see over the bars in published figures.

⚠️ Watch out! Read the NOTE that cld() prints. “Not shown to be different” is not the same claim as “shown to be the same.”

✏️ QA9: Write the letter for each species. Which species share a letter?

Part A10 · The backup that matches Welch

Tukey through emmeans uses the model’s pooled error — the thing Levene warned us about in A6. The unequal-variance version of the same comparisons:

▶ Run this:

pairwise.t.test(penguins_df$body_mass_g,
                penguins_df$species,
                pool.sd = FALSE)

✏️ QA10: Does this table tell the same story as A9’s letters? When the robust version agrees with the standard one, what do you report?

Part A11 · Plot the result

▶ Run this:

mass_emm_df <- as.data.frame(mass_emm$emmeans)

mass_emm_df

mass_emm_plot <- mass_emm_df %>%
  ggplot(aes(x = species, y = emmean)) +
  geom_point(size = 3) +
  geom_errorbar(aes(ymin = lower.CL, ymax = upper.CL),
                width = 0.15)

mass_emm_plot

💡 Key idea: overlapping confidence intervals are a hint, not a test. The p-value is the test; the plot is how a reader sees it.

✏️ QA11: Which intervals overlap, and does that match the pairwise p-values from QA7?

Part A12 · Report the whole thing

A complete write-up names:

  • the assumption you checked and what you did about it
  • the test, F, both df, and p
  • the follow-up, named as adjusted
  • the means, so a reader can see the size of the effect
  • the pair that did not differ — that is a finding, not a failure

✏️ QA12: Write the full results paragraph with your numbers.

"Body mass differed among the three penguin species. Variances were
 unequal (Levene's test: F(__, __) = ____, p = ____), so we report
 Welch's ANOVA: F(__, __) = ____, p ____. Tukey-adjusted comparisons
 showed that ______ was heavier than both ______ (p ____) and ______
 (p ____), while ______ and ______ did not differ (p = ____)."
