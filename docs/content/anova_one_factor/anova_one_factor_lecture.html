One factor, more than two groups, done properly from end to end on real data found on Kaggle: 104 Australian brushtail possums trapped at seven forest sites. Why one test instead of twenty-one t-tests, naming and ordering groups with factor(), fitting lm() and reading car::Anova(type = 2), checking the assumptions AFTER the fit with performance::check_model() and car::leveneTest(), measuring how big the effect is with eta-squared, and finding out WHICH sites differ with emmeans and compact letter displays.

🧩 Chunk 1 of 5 · Why Not Just Do Lots of t-Tests?

We will cover: where the data came from, and the one arithmetic fact that kills the obvious approach.

Finding Data: A Real Search

Your final projects need data. So here is how today’s data was actually found.

Searched kaggle.com/datasets for possum. One hit:

  • “OpenIntro Possum” — 104 rows, 8 columns
  • Uploaded by a user who mirrored it from OpenIntro, a statistics-textbook project
  • OpenIntro got it from a 1995 paper in the Australian Journal of Zoology

So the trail runs: Kaggle → textbook → peer-reviewed field study.

Tip

📖 Always walk the trail back

Kaggle is a mirror, not a source. Anyone can upload anything.

Before you trust a dataset, find out who collected it. If you cannot, that is your answer.

The Animals

Mountain brushtail possum, Trichosurus cunninghami 🐾

  • A nocturnal, tree-dwelling Australian marsupial
  • 104 animals live-trapped at seven forest sites, from Victoria in the south up to Queensland
  • Each animal measured: head length, skull width, total length, tail length, plus age and sex

Our question today:

Do possums from different sites differ in total length?

Note

🧪 One factor, seven levels

  • Response: total_l, total length in cm — a number
  • Factor: site, which forest they were trapped in — seven groups

One factor. That is the whole design, and the name of the test.

The Obvious Idea — And Why It Fails

Seven groups. We know how to compare two. So: compare every pair?

Seven groups make 21 pairs. Twenty-one t-tests.

Each test at \(\alpha = 0.05\) has a 5% chance of a false positive. Run 21 of them on data where nothing is going on:

\[1 - 0.95^{21} = 0.66\]

A 66% chance of at least one “significant” result from pure noise.

Warning

⚠️ This is the whole problem

You would find something. You would find it two times out of three. And it would mean nothing.

More tests is not more rigour. More tests is more chances to fool yourself.

What ANOVA Does Instead

ANOVA asks one question first:

Is there any difference among these seven means?

One question, one p-value, one 5% risk.

It answers by comparing two kinds of variation:

  • Between groups — how far the site means sit from the overall mean
  • Within groups — how much possums at the same site differ from each other

\[F = \frac{\text{variation between groups}}{\text{variation within groups}}\]

Note

🧠 What F means

  • \(F \approx 1\) → groups differ about as much as individuals do. Nothing to see.
  • \(F \gg 1\) → groups differ more than individuals within them do. Something is going on.

“Analysis of variance” is a literal name.

⚠️ One Side Effect of Loading multcomp

multcomp loads MASS, and MASS has its own select(). It masks the dplyr one.

So after today’s library() block, this quietly breaks:

possum_df %>% select(site, total_l)
#> Error: unused arguments

The fix is to say which one you mean:

possum_df %>% dplyr::select(site, total_l)
Warning

⚠️ Watch the startup messages

R told you this when you loaded the package. Nobody reads it.

select() is the usual casualty. filter() is the other one.

None of today’s code uses select() — but your code might.

Warning

⚠️ Those are numbers, and R will treat them as numbers

site arrives as the integers 1–7. To R that is a quantity — as if site 6 were “twice site 3”. It is not. It is a name that happens to be written with a digit.

Leave it like this and lm() will fit a straight line through site number, which is nonsense.

Fix It With factor()

possum_df <- possum_raw %>%
  filter(!is.na(total_l)) %>%
  mutate(site_name = factor(site,
                            levels = 1:7,
                            labels = c("Cambarville", "Bellbird",
                                       "Whian Whian", "Byrangery",
                                       "Conondale", "Allyn River",
                                       "Bulburin")))

possum_df %>% count(site_name)
# A tibble: 7 × 2
  site_name       n
  <fct>       <int>
1 Cambarville    33
2 Bellbird       13
3 Whian Whian     7
4 Byrangery       7
5 Conondale      13
6 Allyn River    13
7 Bulburin       18

What Just Happened

factor(site,
       levels = 1:7,
       labels = c("Cambarville", ...))
  • levels = the values as they appear in the data
  • labels = what you want them called

The two lists must be the same length and in the same order. Get the order wrong and every single result is quietly mislabelled — no error, no warning.

The site names come from the OpenIntro codebook. We did not invent them.

Note

📋 The seven sites

  • Victoria: Cambarville, Bellbird
  • New South Wales: Whian Whian, Byrangery
  • Queensland / N. NSW: Conondale, Allyn River, Bulburin
Warning

⚠️ Unequal groups

33 possums at Cambarville, 7 at Byrangery. That is fine for ANOVA — but it is why we will not hand-calculate anything.

Look Before You Test

ggplot(possum_df, aes(x = site_name, y = total_l)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.15, alpha = 0.5)

What the Plot Already Told Us

Before a single test:

  • Bellbird sits low
  • Byrangery sits high
  • The middle five overlap heavily
  • Boxes are about the same height — spread looks similar across sites
  • No wild outliers

So we expect: a significant overall test, driven by the ends, with the middle a mess.

Tip

🎯 Why this matters

Predicting the answer before you test is not cheating. It is the only way to notice when the output is wrong.

If the test comes back saying nothing differs, you now know to go looking for a mistake.

A Warning About the Obvious Story

Seven sites on a north–south gradient. Tempting story:

Colder in the south → bigger animals. Bergmann’s rule.

Look again. The two Victorian sites are the southernmost — and they are at opposite extremes:

  • Cambarville 89.7 cm
  • Bellbird 81.8 cm

Two sites, same state, 8 cm apart. Latitude cannot explain that.

Warning

⚠️ Do not let the test write your story

A significant F tells you the sites differ. It says nothing about why.

“Sites differ” is the finding. “Because of latitude” would be a second claim, and this data does not support it.

🧩 Chunk 3 of 5 · Fit the Model, Run the Test

We will cover: lm() for more than two groups, then car::Anova() and how to read its table.

Fit It With lm() — Same Function as Always

total_model <- lm(total_l ~ site_name, data = possum_df)
Note

🧠 Nothing new here

response ~ predictor, exactly as in regression. The only change is that the predictor is a factor with seven levels instead of a number.

lm() does not need a different function for ANOVA. ANOVA is a linear model. That is not a simplification — it is literally the same machinery.

Do Not Read summary() First

summary(total_model)   # six rows of "site_nameBellbird" etc.

summary() gives you six slopes, each comparing one site to Cambarville — because Cambarville is level 1, so it became the baseline.

That answers “is each site different from Cambarville?”, which is not the question. Nobody asked about Cambarville.

Warning

⚠️ The wrong table

Six p-values, all against an arbitrary reference group. Change which site is level 1 and all six change.

We want one p-value for site_name as a whole.

The Right Table: car::Anova()

Anova(total_model, type = 2)
Anova Table (Type II tests)

Response: total_l
           Sum Sq Df F value    Pr(>F)    
site_name  907.59  6  14.582 8.452e-12 ***
Residuals 1006.24 97                      
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
Important

✅ This is the result

F(6, 97) = 14.58, p = 8.45 × 10⁻¹²

One line. One p-value. One question answered: the seven site means are not all the same.

Reading That Table

  • Sum Sq 907.6 — variation explained by site
  • Sum Sq 1006.2 — variation left over within sites
  • Df 6 — seven groups minus one
  • Df 97 — 104 possums minus 7 groups
  • F value 14.58 — the ratio, after dividing each Sum Sq by its Df
  • Pr(>F) — how often an F this big happens when nothing is going on

\(F = 14.58\) means between-site variation is 14 and a half times within-site variation.

Note

🔢 Why type = 2?

With one factor, Type I, II and III all give the identical answer. It genuinely does not matter here.

We write type = 2 anyway, as a habit, because the moment you add a second factor it starts mattering a great deal.

How Big Is It? F Does Not Tell You

effectsize::eta_squared(Anova(total_model, type = 2), partial = FALSE)
# Effect Size for ANOVA (Type II)

Parameter | Eta2 |       95% CI
-------------------------------
site_name | 0.47 | [0.34, 1.00]

- One-sided CIs: upper bound fixed at [1.00].

Eta-squared (\(\eta^2\)) = 0.47.

Which site a possum came from accounts for 47% of all the variation in total length.

The other 53% is possums being individuals.

Tip

🎯 p ≠ size

p answers “is it real?” \(\eta^2\) answers “is it big?”

With a big enough sample, a trivial difference gets a tiny p. Always report both.

🧩 Chunk 4 of 5 · Check the Assumptions

We will cover: what ANOVA assumes, why you check it after fitting, and two packages that do the work.

Two Assumptions, Checked on the Residuals

  1. Equal variances across groups — each site is about equally spread
  2. Normal residuals — what the model missed is normally distributed

Plus one you check by thinking, not testing:

  1. Independence — each possum is one animal, trapped once, measured once ✅
Important

⚠️ Order matters

You cannot check residuals before you have residuals. So:

fit first, then check.

If the check fails you go back and change the model — you do not delete the data.

The Visual Check — check_model()

check_model(total_model, check = c("homogeneity", "qq"))

What You Are Looking For

Those are the two panels that match our two assumptions:

  • Homogeneity of variance — the line should be flat. A slope or a wedge means spread changes across groups
  • Normality of residuals — the dots should hug the diagonal

Both look healthy here. That is a boring plot, and boring is exactly what you want.

Note

📺 On your screen you get five

Plain check_model(total_model) draws all five:

  • posterior predictive check
  • linearity
  • homogeneity of variance
  • influential observations
  • normality of residuals

We asked for two here only so they fit on a slide.

If check_model() Throws an Error

Five panels need room. If the RStudio Plots pane is small, check_model() fails with a complaint about the plot size rather than drawing anything.

Two fixes:

  • Drag the Plots pane bigger and run it again, or
  • Ask for fewer panels, as we did above:
check_model(total_model,
            check = c("homogeneity", "qq"))
Warning

⚠️ Not your code

This error is about your window, not your model. Nothing is wrong with the analysis.

It catches everybody once.

The Formal Tests

# Equal variances across sites
leveneTest(total_l ~ site_name, data = possum_df)
Levene's Test for Homogeneity of Variance (center = median)
      Df F value Pr(>F)
group  6  0.5032 0.8046
      97               
# Normal residuals
shapiro.test(residuals(total_model))

    Shapiro-Wilk normality test

data:  residuals(total_model)
W = 0.98939, p-value = 0.588

Same Two Checks, Said in English

check_homogeneity(total_model)
OK: There is not clear evidence for different variances across groups (Bartlett Test, p = 0.867).
check_normality(total_model)
OK: residuals appear as normally distributed (p = 0.602).
Important

✅ Both assumptions pass

  • Levene p = 0.805 → no evidence variances differ
  • Shapiro–Wilk p = 0.588 → no evidence residuals are non-normal

High p-values are the good outcome here. You are hoping not to reject.

Careful: These Tests Are Backwards

For the main test, a small p was the interesting result.

For assumption tests it is the opposite — a small p means your test is in trouble.

That inversion catches people constantly. Say it out loud each time:

“Levene p = 0.805. Big. Variances are fine. Carry on.”

Warning

⚠️ And do not over-trust them

With small groups these tests are weak — they pass almost anything.

With huge samples they are brutal — they fail on differences too small to matter.

Look at check_model() as well, always.

🧩 Chunk 5 of 5 · Which Sites Actually Differ?

We will cover: why F is not the end, emmeans, Tukey adjustment, and reading a compact letter display.

F Said “Not All Equal” — That Is All It Said

We have F(6, 97) = 14.58, p < 0.001.

That is: at least one site differs from at least one other.

It does not tell you:

  • which sites
  • how many
  • in which direction

For that you need post-hoc comparisons — “after the fact”.

Note

🧠 Why this is allowed now

Doing 21 comparisons was wrong as a first move.

Doing them after a significant F, with the p-values adjusted, is the standard, defensible approach.

The gate came first.

The Count

Of the 21 pairs, 10 are significant and 11 are not.

Which is exactly what the boxplot predicted:

  • Everything involving Bellbird (lowest) or Byrangery (highest) tends to separate
  • The middle five mostly do not separate from each other

Twenty-one rows is a lot to read. There is a better way to show it.

Tip

🎯 Report the pattern

Nobody wants 21 p-values in a results section.

They want to know which groups cluster together. That is what letters do.

How to Read Letters

Share a letter → not shown to differ. No letter in common → differ.

  • Bellbird a — alone at the bottom
  • Allyn River ab — not distinguishable from either neighbour
  • Byrangery d — alone at the top
  • Bellbird vs Byrangery: a vs d, nothing shared → differ

A clean ladder from 81.8 cm up to 92.2 cm.

Warning

⚠️ Read R’s own note

“If two or more means share the same grouping symbol, then we cannot show them to be different. But we also did not show them to be the same.”

Sharing a letter is failure to detect a difference — not evidence of equality. Especially at Byrangery, where n = 7.

Put the Letters on the Plot

letters_df <- as.data.frame(cld(site_means, Letters = letters)) %>%
  mutate(group = trimws(.group))

ggplot(possum_df, aes(x = site_name, y = total_l)) +
  geom_boxplot(outlier.shape = NA) +
  geom_jitter(width = 0.15, alpha = 0.4) +
  geom_text(data = letters_df,
            aes(x = site_name, y = 97, label = group),
            size = 5)

Writing It Up

Important

📝 The whole result, in three sentences

Total length differed significantly among the seven trapping sites (one-way ANOVA, F(6, 97) = 14.58, p < 0.001), and site accounted for 47% of the variation in length (η² = 0.47). Residuals were normally distributed (Shapiro–Wilk p = 0.59) with homogeneous variances across sites (Levene’s test p = 0.81). Tukey-adjusted comparisons separated Bellbird (mean 81.8 cm) from Byrangery (92.2 cm), with the remaining five sites forming an overlapping middle group.

What Belongs in That Sentence

Every number has a job:

  • The test — one-way ANOVA
  • F with both df — F(6, 97); the df let a reader reconstruct your design
  • p — as p < 0.001, not p = 0
  • Effect size — η², because p alone hides size
  • Assumption checks — so the reader knows you looked
  • The pattern — which groups, in which direction, with means
Warning

⚠️ Never write “p = 0.000”

Software rounds. Probability does not reach zero.

Write p < 0.001 and move on.

Common Ways This Goes Wrong

  • Grouping variable left as a number → you fit a line through site IDs
  • Reading summary() instead of Anova() → six wrong p-values
  • Checking assumptions before fitting → there are no residuals yet
  • Expecting a small p for Levene → backwards
  • Stopping at a significant F → F never says which groups
  • Unadjusted pairwise tests → the 66% problem, straight back
  • Calling shared letters “the same” → they are undetected, not equal
Tip

🎯 The recipe, memorised

  1. factor() the groups
  2. Plot it
  3. lm()
  4. Anova(type = 2)
  5. check_model() + leveneTest()
  6. eta_squared()
  7. emmeans() → pairs() → cld()
  8. Write the sentence

Recap

  • Many t-tests inflate error — 7 groups, 21 pairs, 66% false-positive risk
  • ANOVA asks one question: between-group variation vs within-group variation
  • factor(levels =, labels =) turns group codes into named, ordered groups
  • lm() fits it — ANOVA is a linear model; car::Anova(type = 2) gives the one right table
  • Check after fitting — check_model(), leveneTest(), shapiro.test(); here a big p is good
  • η² says how big; F only says whether
  • emmeans() → pairs() → cld() says which — with p-values adjusted
  • Shared letters mean not shown to differ, never shown to be the same
