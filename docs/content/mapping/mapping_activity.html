🧩 Chunk 1 — Bigfoot, for fun (after lecture Chunk 1)

Parts 1–3: lat/long becomes a map.

Part 1 · Load up and read the sightings

▶ Run this:

# Load libraries ---------------------------------------
library(tidyverse)
library(sf)       # spatial data frames
library(maps)     # ready-made country and state outlines
library(rgbif)    # download species records from GBIF
library(leaflet)  # live, zoomable maps

▶ Run this:

# Bigfoot reports, trimmed to the lower 48 -------------
bigfoot_df <- read_csv("data/bfro_reports_geocoded.csv") %>%
  filter(!is.na(latitude), !is.na(longitude)) %>%
  filter(longitude > -125, longitude < -66,
         latitude  >   24, latitude  <  50)

nrow(bigfoot_df)

⚠️ Watch out! Those four numbers are a bounding box — a crude rectangle around the lower 48. It throws Alaska and Hawaii away on purpose. Remember that: in Part 7 we will want Alaska back, and this is the line that would have eaten it.

Part 2 · Make it spatial

🔮 Predict first: you are about to plot ~4,000 points with no basemap at all. What shape will the cloud of points make?

▶ Run this:

# Turn lon/lat into a geometry column ------------------
bigfoot_sf <- bigfoot_df %>%
  st_as_sf(coords = c("longitude", "latitude"), crs = 4326)

ggplot(bigfoot_sf) +
  geom_sf(alpha = 0.2, size = 0.5)

✏️ Q1: In coords = c("longitude", "latitude"), which comes first — x or y? What happens if you swap them?

✏️ Q2: The points drew a recognizable USA with no map underneath. What does that tell you about what a “map” actually is?

💡 Key idea: an sf object is a data frame with one extra column — geometry. Every dplyr verb you already know still works on it.

Part 3 · Put it on a real map

▶ Run this:

# State outlines -> sf ---------------------------------
states_sf <- st_as_sf(
  maps::map("state", plot = FALSE, fill = TRUE)
) %>%
  st_set_crs(4326)

# Basemap first, points on top -------------------------
ggplot() +
  geom_sf(data = states_sf, fill = "grey96", color = "grey75") +
  geom_sf(data = bigfoot_sf, alpha = 0.2, size = 0.5, color = "firebrick") +
  theme_void()

✏️ Q3: Why does the order of the two geom_sf() layers matter — what would you see if you drew them the other way around?

✏️ Q4: Is this map about Bigfoot, or about people — where they live, hike, and file reports? What would tell those apart?

That last question is the whole reason we start here. Bigfoot is a joke dataset with a serious lesson in it: an occurrence map shows you where someone looked, not only where the thing is. Hold onto that — the moose data has exactly the same problem.

🧩 Chunk 2 — Real occurrence data: GBIF (after lecture Chunk 2)

Parts 4–5: download actual species records.

Part 4 · Meet GBIF

GBIF — the Global Biodiversity Information Facility — pools occurrence records from museums, herbaria, survey programs, and apps like iNaturalist. Billions of records, free, and the rgbif package queries it straight from R.

Today’s species is the moose, Alces alces. You need the scientific name — GBIF does not take “moose.”

▶ Run this:

# Up to 2000 US moose records that have coordinates ----
moose_raw <- occ_data(
  scientificName = "Alces alces",
  country        = "US",
  hasCoordinate  = TRUE,
  limit          = 2000
)$data

dim(moose_raw)
  • scientificName — genus and species, spelled exactly
  • country = "US" — a two-letter country code
  • hasCoordinate = TRUE — skip records with no lat/long; they are useless to us
  • limit — how many records to bring back
  • $data on the end — occ_data() hands back a list, and the records are in its data slot

⚠️ Watch out! 119 columns arrive. GBIF records carry everything anyone ever recorded — collector, institution, elevation, licence. We want five of them.

Part 5 · What did limit actually give you?

▶ Run this:

# How many US moose records does GBIF actually have? ---
occ_count(scientificName = "Alces alces", country = "US")

# And what years did OUR 2000 records come from? -------
moose_raw %>%
  count(year, sort = TRUE)

✏️ Q5: GBIF holds about 28,000 US moose records. You asked for 2,000 — and they all came from one year. So what does limit actually do: take a random sample, or take the first 2,000 GBIF hands back?

✏️ Q6: If you mapped these 2,000 and called it “the range of moose in the US,” what would be wrong with that claim?

💡 Key idea: limit is not a sample, it is a cutoff. Every occurrence map you will ever make is a map of sampling effort as much as of the species. Say so out loud when you present one.

🧩 Chunk 3 — Map the moose, Alaska included (after lecture Chunk 3)

Parts 6–7: clean it, then map the whole country.

Part 6 · Trim and make it spatial

▶ Run this:

# Five columns is plenty -------------------------------
moose_df <- moose_raw %>%
  select(species, stateProvince, decimalLatitude,
         decimalLongitude, year) %>%
  filter(!is.na(decimalLongitude), !is.na(decimalLatitude))

moose_df %>%
  count(stateProvince, sort = TRUE) %>%
  head()

▶ Run this:

# Same st_as_sf() as Bigfoot, different column names ---
moose_sf <- moose_df %>%
  st_as_sf(coords = c("decimalLongitude", "decimalLatitude"),
           crs = 4326)

moose_sf

GBIF calls its coordinates decimalLongitude and decimalLatitude. The recipe did not change — only the names you hand to coords. Longitude still goes first.

✏️ Q7: Which state has the most moose records? Does that surprise you?

Part 7 · A basemap with Alaska in it

Our states_sf from Part 3 is the lower 48 only — it has no Alaska. The single biggest cluster of moose records in the country is in Alaska, so we need a different basemap.

▶ Run this:

# Country outlines, Alaska included --------------------
usa_sf <- st_as_sf(
  maps::map("world", regions = "USA", plot = FALSE, fill = TRUE)
) %>%
  st_set_crs(4326)

# Moose across the whole country -----------------------
ggplot() +
  geom_sf(data = usa_sf, fill = "grey96", color = "grey75") +
  geom_sf(data = moose_sf, alpha = 0.3, size = 0.7, color = "darkgreen") +
  coord_sf(xlim = c(-170, -60), ylim = c(25, 72)) +
  theme_void()

The coord_sf() limits are doing real work here. Without them the map stretches from Maine to the far end of the Aleutian Islands — which cross the international date line — and the whole country squashes into a sliver.

✏️ Q8: Where are the moose? Name the regions. Does that match what you know about the species — and about where it is cold?

✏️ Q9: There are no moose in the southern US on this map. Is that a real range limit, or a sampling artifact like the Bigfoot map? How is this case different?

🧩 Chunk 4 — Go live (after lecture Chunk 4)

Parts 8–9: a map you can actually zoom.

Part 8 · Your first live map

Everything so far has been a picture. leaflet makes a real web map — tiles, pan, zoom, scroll — right inside RStudio’s Viewer pane.

▶ Run this:

# A map you can zoom -----------------------------------
leaflet(moose_sf) %>%
  addTiles() %>%
  addCircleMarkers(radius = 4, stroke = FALSE,
                   fillOpacity = 0.6, color = "darkgreen")

Three lines:

  • leaflet(moose_sf) — start a map from your sf object
  • addTiles() — put the actual world map underneath, streamed from the web
  • addCircleMarkers() — drop a dot on every record

Zoom in. Scroll onto Anchorage, onto the Colorado Rockies, onto Maine. This is the same data as Part 7 — but now you can ask it questions by looking.

✏️ Q10: Zoom all the way in on a cluster. Do the points land in forest and wetland, or do they line up along roads and towns? What does that tell you about how these records were collected?

Part 9 · Labels on the dots

▶ Run this:

# Click any dot to see what it is ----------------------
leaflet(moose_sf) %>%
  addTiles() %>%
  addCircleMarkers(
    radius      = 4,
    stroke      = FALSE,
    fillOpacity = 0.6,
    color       = "darkgreen",
    popup       = ~paste0(species, "<br>", stateProvince, "<br>", year)
  )

The ~ makes popup a formula — “look these columns up in the data for each row.” <br> is a line break, because the popup is a little web page.

✏️ Q11: Click a few dots. Is every record the species you asked for?

💡 Key idea: the recipe never changed. Get coordinates → st_as_sf() → draw them. Bigfoot, moose, or anything you download next semester — same four steps, different file.

Part 10 · If there is time — sightings per state

This is the left_join() from last class, pointed at a map. Counts are one table, polygons are another, and state is the key.

▶ Run this:

# Count Bigfoot sightings per state --------------------
sightings_by_state <- bigfoot_df %>%
  mutate(state = str_to_lower(state)) %>%
  count(state, name = "sightings")

# Join the counts onto the state polygons --------------
states_map <- states_sf %>%
  mutate(state = str_remove(ID, ":.*")) %>%   # drop ":north" etc.
  left_join(sightings_by_state, by = "state")

▶ Run this:

# The map IS the bar chart -----------------------------
ggplot(states_map) +
  geom_sf(aes(fill = sightings), color = "white") +
  scale_fill_viridis_c(option = "magma", direction = -1) +
  coord_sf(crs = 5070) +
  theme_void()

direction = -1 flips the scale so more sightings = darker; the default reads backwards to most people. coord_sf(crs = 5070) is an equal-area projection for the lower 48 — which is why we did not use it on the moose map, where Alaska would have been mangled.

✏️ Q12: Exactly one polygon comes back NA and draws grey. Is that a broken join or a true zero — and how would you tell?

✏️ Q13: Washington and California are big, populous, and forested. What extra data would make this a fair state-to-state comparison?

Homework — map a species of your own

Open 17_mapping_homework.R. That file — not today’s script — is what you turn in.

You pick one species you actually care about (or several, if you want to compare them) and run today’s recipe on it:

  1. Look up its scientific name — GBIF will not take a common name
  2. occ_data() it from GBIF
  3. Check what you actually got — how many records, and from when
  4. st_as_sf() and map it on the US basemap
  5. Make it live with leaflet
  6. Say whether the map matches the range you expected, and where sampling effort is showing through

Everything you need is in the homework skeleton, with the moose code sitting right there as the worked example to copy from. The written answers go in as # comments.
