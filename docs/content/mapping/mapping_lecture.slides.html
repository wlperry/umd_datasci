What Is Spatial Data?

Three ideas and you have it:

  • Points — one coordinate pair. A sighting, a tree, a weather station.
  • Polygons — a closed ring of coordinates. A state, a lake, a park.
  • CRS — the coordinate reference system: what the numbers mean.

4326 is plain latitude/longitude in degrees — what a phone GPS gives you, and what almost every dataset arrives in.

Note

📖 Vocabulary

Two datasets will not line up unless they share a CRS. Most mismatched-map bugs are two layers in two different systems.

The sf Package — a Data Frame with Geometry

# Load packages + the sighting data ------------------
library(tidyverse)
library(sf)       # spatial data frames
library(maps)     # country + state outlines
library(rgbif)    # species records from GBIF
library(leaflet)  # live maps

# The file is in your data/ folder ------------------
bigfoot_df <- read_csv("data/bfro_reports_geocoded.csv")

dim(bigfoot_df)
[1] 5021   29
  • An sf object is a tibble with one extra column, geometry
  • Every dplyr verb you know still works on it
  • ~5,000 real BFRO reports, each geocoded to a lat/long

Clean the Coordinates First

# Drop missing coords + keep the lower 48 ------------
bigfoot_df <- bigfoot_df %>%
  filter(!is.na(latitude), !is.na(longitude)) %>%
  filter(longitude > -125, longitude < -66,
         latitude  >   24, latitude  <  50)

nrow(bigfoot_df)
[1] 4031
  • st_as_sf() errors on missing coordinates — filter them first
  • The four numbers are a bounding box around the lower 48

Warning

⚠️ Remember this line. It throws Alaska away on purpose. In Chunk 3 we want Alaska back, and this is what would have eaten it.

Make It Spatial — st_as_sf()

Note

🔮 Predict first: ~4,000 rows of lat/long, plotted with no basemap. What shape will the cloud make?

# Build the geometry column from lon/lat -------------
bigfoot_sf <- bigfoot_df %>%
  st_as_sf(coords = c("longitude", "latitude"),
           crs = 4326)

# Just the points — the USA appears on its own -------
ggplot(bigfoot_sf) +
  geom_sf(alpha = 0.2, size = 0.5)
  • coords = c("longitude", "latitude") — x first, always
  • crs = 4326 — tell sf these are degrees
  • No map needed: the data drew the country

Put It on a Real Map

# Basemap first, then points on top ------------------
states_sf <- st_as_sf(
  maps::map("state", plot = FALSE, fill = TRUE)
) %>%
  st_set_crs(4326)

ggplot() +
  geom_sf(data = states_sf,
          fill = "grey96", color = "grey75") +
  geom_sf(data = bigfoot_sf, alpha = 0.2,
          size = 0.5, color = "firebrick") +
  theme_void()
  • Order matters — states first, points on top
  • theme_void() drops axes and grid

Note

🤔 The real question

Is this a map of Bigfoot, or a map of where people live, hike, and file reports? Hold that thought — the moose data has the same problem.

Where Real Occurrence Data Lives

GBIF — the Global Biodiversity Information Facility — pools occurrence records from:

  • museum and herbarium collections
  • government survey programs
  • citizen science apps like iNaturalist

Billions of records. Free. And rgbif queries it straight from R — no website, no download button.

Warning

⚠️ Scientific names only

GBIF does not know “moose.” It knows Alces alces. Common names are ambiguous across languages and regions; the binomial is not.

Downloading Moose 🫎

# Up to 2000 US moose records with coordinates -------
moose_raw <- occ_data(
  scientificName = "Alces alces",
  country        = "US",
  hasCoordinate  = TRUE,
  limit          = 2000
)$data

dim(moose_raw)
[1] 2000  119
  • scientificName — genus + species, spelled exactly
  • country = "US" — two-letter code
  • hasCoordinate = TRUE — skip records we can’t map
  • limit — how many to bring back
  • $data — occ_data() returns a list; the records are in its data slot

119 columns arrive. We want five.

What Did limit Actually Give You?

# How many US moose records EXIST? -------------------
occ_count(scientificName = "Alces alces",
          country = "US")
[1] 28004
# What years did OUR 2000 come from? -----------------
moose_raw %>%
  count(year, sort = TRUE)
# A tibble: 1 × 2
   year     n
  <int> <int>
1  2026  2000

About 28,000 records exist. We asked for 2,000 — and they all came from one year.

Important

limit is a cutoff, not a sample.

It hands back the first n records GBIF returns, newest first. Map those and call it “the range” and you are making a claim your data cannot support.

🧩 Chunk 3 of 4 · Map the Moose — Alaska Included

Tip

🖐 After this chunk: Activity Parts 6–7 (trim it, then map the whole country).

Trim It and Make It Spatial

# Five columns is plenty -----------------------------
moose_df <- moose_raw %>%
  select(species, stateProvince, decimalLatitude,
         decimalLongitude, year) %>%
  filter(!is.na(decimalLongitude),
         !is.na(decimalLatitude))

moose_sf <- moose_df %>%
  st_as_sf(coords = c("decimalLongitude",
                      "decimalLatitude"),
           crs = 4326)

moose_df %>% count(stateProvince, sort = TRUE) %>% head(4)
# A tibble: 4 × 2
  stateProvince     n
  <chr>         <int>
1 Alaska          641
2 Colorado        469
3 Wyoming         261
4 Idaho           107

GBIF names its coordinates decimalLongitude / decimalLatitude.

The recipe did not change — only the names you hand to coords. Longitude still goes first.

Alaska has more moose records than anywhere else. Which is a problem…

The Lower-48 Basemap Problem

states_sf from Chunk 1 is the lower 48 only. It has no Alaska at all — so the biggest cluster of moose in the country would simply not be drawn.

# Country outlines, Alaska included ------------------
usa_sf <- st_as_sf(
  maps::map("world", regions = "USA",
            plot = FALSE, fill = TRUE)
) %>%
  st_set_crs(4326)

Warning

⚠️ Two traps at once

  1. The Aleutians cross the date line, so the raw extent runs −178 to +180 and squashes the country to a sliver. coord_sf() limits fix it.
  2. crs = 5070 is CONUS Albers — it mangles Alaska. Leave this map unprojected.

Moose Across the Country

ggplot() +
  geom_sf(data = usa_sf,
          fill = "grey96", color = "grey75") +
  geom_sf(data = moose_sf, alpha = 0.3,
          size = 0.7, color = "darkgreen") +
  coord_sf(xlim = c(-170, -60),
           ylim = c(25, 72)) +
  theme_void()

Read the biology off it:

  • Alaska, the northern Rockies, the upper Midwest, New England
  • Nothing in the south — moose are a cold-adapted animal with a real southern limit

Unlike Bigfoot, this pattern is mostly the species, not only the observers. Mostly.

leaflet — a Real Web Map

# A map you can zoom ---------------------------------
leaflet(moose_sf) %>%
  addTiles() %>%
  addCircleMarkers(radius = 4, stroke = FALSE,
                   fillOpacity = 0.6,
                   color = "darkgreen")

Three lines:

  • leaflet(moose_sf) — start from your sf object
  • addTiles() — the actual world map, streamed from the web
  • addCircleMarkers() — a dot per record

Important

▶ Run this one yourself

It opens in the RStudio Viewer pane. It can’t be printed onto a slide — the whole point is that it moves.

Zoom in: Anchorage. The Colorado Rockies. Maine.

Click a Dot — Popups

leaflet(moose_sf) %>%
  addTiles() %>%
  addCircleMarkers(
    radius      = 4,
    stroke      = FALSE,
    fillOpacity = 0.6,
    color       = "darkgreen",
    popup       = ~paste0(species, "<br>",
                          stateProvince, "<br>", year)
  )
  • ~ makes popup a formula — look these columns up for each row
  • <br> is a line break, because a popup is a tiny web page

Note

🤔 Zoom all the way in

Do the points sit in habitat — or do they trace roads, towns, and trailheads? That is sampling effort, visible with your own eyes.

What We Learned Today

Concepts:

  • Spatial data = points/polygons + a CRS
  • sf objects are tibbles with a geometry column
  • geom_sf() draws layers; order matters (basemap first)
  • GBIF holds real occurrence records for nearly any species
  • limit is a cutoff, not a sample — every occurrence map is partly a map of sampling effort
  • A lower-48 basemap silently drops Alaska

R skills:

  • st_as_sf(), st_set_crs(), maps::map(), coord_sf()
  • occ_data(), occ_count() from rgbif
  • leaflet(), addTiles(), addCircleMarkers()
