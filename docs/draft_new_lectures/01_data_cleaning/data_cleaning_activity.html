Cleaning Our Messy Leaf Data

Recap from the lecture

  • glimpse(), skim(), and count() are how you find messiness
  • janitor::clean_names() standardizes column names
  • str_trim() + str_to_lower() fix inconsistent text categories
  • read_csv(na = c(...)) and na_if() fix disguised missing-value codes
  • parse_number() rescues numbers that were accidentally typed as text
  • duplicated() finds repeat rows; distinct() removes them
  • Flag suspicious values with mutate() — never silently delete them

How to use this worksheet

Work through each part in order. Type every line yourself. Blocks marked ▶ Run this should be executed exactly as written. Blocks marked ✏️ Your turn ask you to write or modify code. The Going further section is optional.

🔮 Predict before you run — and type, don’t paste

Before every ▶ Run this block, guess what R will print. The gap between your guess and the real output is where the learning happens — and typing (not pasting) trains your eye to catch the exact typos that make messy data messy in the first place.

Try case_when() for a three-way recode

leaf_flagged_df %>%
  mutate(size_class = case_when(
    weight_g < 5             ~ "small",

    weight_g >= 7             ~ "large",

Getting unstuck

  1. Read the error message out loud. R usually names the line and the problem.
  2. clean_names not found? Run library(janitor) — and install.packages("janitor") once if needed.
  3. Still seeing extra categories after str_trim() + str_to_lower()? There may be a genuine typo (e.g. "suny"), not just case or whitespace — count() again to see exactly what’s left.
  4. parse_number() returns NA for everything? Check you spelled the column name correctly with names(leaf_raw_df).
  5. Not sure if a value is a typo or real? Flag it and go back to the original field notebook or data source — never guess silently.
  6. Bring the exact error (copy-paste it) to class, Canvas, or office hours.

💡 Key idea: Cleaning is not a detour before “the real analysis” — it is the real analysis. A beautiful t-test on uncleaned data is just a beautifully wrong answer.
