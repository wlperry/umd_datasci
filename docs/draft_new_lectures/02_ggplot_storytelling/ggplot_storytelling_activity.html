Redesigning a Plot That Says Nothing

Recap from the lecture

  • Start from a finished sentence: “This figure shows that ____.”
  • The five-second test — does a stranger repeat your finding back?
  • Cut redundancy (repeated legends/facets), drop unneeded legends, order categories with intent
  • Color with intent and colorblind safety in mind
  • Title = finding, subtitle = method, caption = fine print
  • annotate() to point at exactly one thing

How to use this worksheet

Work through Parts 1–7 in order, typing every line yourself. Part 8 asks you to redesign a second plot from scratch with no scaffolding — that is the real test of whether today’s ideas stuck.

Part 6 · Fix #5 — a title that states the finding

▶ Run this:

tree_final_plot <- tree_df %>%
  mutate(side = fct_relevel(side, "sunny", "shady")) %>%
  ggplot(aes(x = side, y = weight_g, fill = side)) +
  geom_boxplot(alpha = 0.7, outlier.shape = NA) +
  geom_jitter(width = 0.15, alpha = 0.6, size = 2) +
  scale_fill_manual(values = c(sunny = "#E69F00", shady = "#0072B2")) +
  labs(
    title = "Shady-side leaves are heavier than sunny-side leaves",
    subtitle = "Each point is one leaf; boxes show the median and interquartile range",
    x = NULL,
    y = "Leaf weight (g)",
    caption = "n = 10 leaves per side"
  ) +
  theme_minimal() +
  theme(legend.position = "none", plot.title = element_text(face = "bold"))

Part 7 · Fix #6 — annotate() to point at the finding

mean_shady <- tree_df %>% filter(side == "shady") %>%
  summarize(m = mean(weight_g, na.rm = TRUE)) %>% pull(m)

tree_final_plot +

    "text", x = 2.35, y = mean_shady,

Part 9 · Review and checkpoint

At this point you should be able to:

Getting unstuck

  1. Legend won’t disappear? Check you used theme(legend.position = "none"), not theme(legend.position = NULL).
  2. fct_relevel() error? The column must already be a factor or character — check with class(tree_df$side).
  3. Colors look wrong? scale_fill_manual() names must exactly match the values in your data — check with unique(tree_df$side).
  4. Annotation label is cut off or overlapping? Adjust the x/y coordinates — they are in the same units as your axes, not fixed screen positions.
  5. Bring the exact error (copy-paste it) to class, Canvas, or office hours.

💡 Key idea: A finding-based title is the cheapest, highest-impact edit you can make to any figure. If you do nothing else from today’s lecture, do that one.
